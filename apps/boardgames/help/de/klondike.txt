Klondike-Solitär
# Das Ziel
Alle 52 Karten auf die vier Ablagestapel bringen, einen für jede Farbe, aufsteigend vom Ass bis zum König.
# Der Aufbau
- Sieben Spalten mit 1 bis 7 Karten; nur die oberste Karte jeder Spalte liegt offen.
- Die übrigen 24 Karten sind der Stapel.
# Karten bewegen
- Auf eine Spalte kommt eine Karte, die einen Rang niedriger ist und die andere Farbe hat: eine rote 6 auf eine schwarze 7.
- Offene Karten, die aufeinander folgen, ziehen zusammen.
- Nur ein König oder eine Reihe, die mit einem König beginnt, darf eine leere Spalte füllen.
- Liegt oben auf einer Spalte eine verdeckte Karte, wird sie aufgedeckt.
- Eine Karte von einem Ablagestapel darf zurück auf eine Spalte.
# Der Stapel
- Eine Karte ziehen: Tippe auf den Stapel, um eine Karte aufzudecken. Drei Karten ziehen: drei auf einmal, und nur die oberste ist spielbar.
- Drehe die gezogenen Karten so oft um, wie du willst.
# Das Ende der Partie
Du gewinnst, wenn alle Karten auf den Ablagestapeln liegen.
# Level und Sterne
3 Sterne: ohne Tipp und ohne Rücknahme.
