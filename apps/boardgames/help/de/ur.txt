Königliches Spiel von Ur
# Das Ziel
Bringe deine sieben Steine vor dem anderen Spieler über deinen Weg und vom Brett. Elfenbein würfelt zuerst.
# Das Brett
Dein Weg führt über deine eigenen vier Felder, dann die ganze gemeinsame mittlere Reihe entlang, dann über deine eigenen letzten zwei Felder und vom Brett.
# Würfeln und Ziehen
- Wirf die vier Würfel und zähle die markierten Spitzen, die nach oben zeigen: 0 bis 4.
- Ziehe einen Stein um so viele Felder weiter; ein Wurf von 3 setzt einen neuen Stein auf dein drittes Feld.
- Du kannst nicht auf einem eigenen Stein landen.
- Eine 0 oder ein Wurf, den kein Stein nutzen kann, verfällt.
# Rosetten
Landest du auf einer Rosette, bekommst du einen weiteren Wurf. Die mittlere Rosette ist außerdem sicher: Niemand darf dort auf einem Stein landen.
# Schlagen
Landest du in der gemeinsamen Reihe auf einem gegnerischen Stein, muss er zurück vom Brett.
# Auswürfeln
Ein Stein verlässt das Brett nur mit der genauen Zahl: eine 1 von deinem letzten Feld, eine 2 vom Feld davor und so weiter.
# Das Ende der Partie
Wer zuerst alle sieben Steine ausgewürfelt hat, gewinnt.
