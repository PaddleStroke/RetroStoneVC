Breakthrough
# Das Ziel
Bringe als Erster eine deiner Figuren auf die andere Seite des Bretts, die Grundreihe des anderen Spielers. Hell beginnt.
# So ziehen die Figuren
- Eine Figur zieht ein Feld vorwärts, geradeaus oder diagonal, auf ein leeres Feld.
- Sie schlägt, indem sie ein Feld diagonal vorwärts auf eine gegnerische Figur zieht. Sie schlägt nie geradeaus: Eine gegnerische Figur direkt vor ihr blockiert sie.
- Figuren ziehen nie zur Seite oder rückwärts. Schlagen ist nie Pflicht.
# Das Ende der Partie
- Wer zuerst die Grundreihe des anderen Spielers erreicht, gewinnt.
- Wer alle seine Figuren verliert, verliert die Partie.
Es gibt kein Remis.
