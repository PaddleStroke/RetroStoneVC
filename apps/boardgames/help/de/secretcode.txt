Geheimcode
# Das Ziel
Finde allein den versteckten Code aus farbigen Steckern heraus, bevor die Reihen ausgehen. Im leichten Spiel kommt keine Farbe im Code zweimal vor; sonst dürfen sich Farben wiederholen.
# Ein Zug
Fülle die nächste Reihe mit einem Stecker in jedem Loch und lass sie dann prüfen. Kleine Stecker antworten:
- Ein dunkler für jeden Stecker der richtigen Farbe im richtigen Loch.
- Ein heller für jeden anderen Stecker, dessen Farbe im Code vorkommt, aber woanders. Jeder Stecker des Codes antwortet nur einmal.
Die Antwortstecker verraten nie, welche deiner Stecker sie meinen.
# Das Ende der Partie
Du gewinnst, sobald eine Reihe dem Code gleicht: Alle ihre Antwortstecker sind dunkel. Scheitert die letzte Reihe, verlierst du.
