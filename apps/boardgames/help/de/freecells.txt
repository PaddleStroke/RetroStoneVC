Freie Zellen
# Das Ziel
Alle 52 Karten auf die vier Ablagestapel bringen, einen für jede Farbe, aufsteigend vom Ass bis zum König.
# Der Aufbau
- Die 52 Karten liegen offen in acht Spalten, unter vier freien Zellen und den vier Ablagestapeln.
# Karten bewegen
- Bewegt wird die oberste Karte einer Spalte: auf eine Karte, die einen Rang höher ist und die andere Farbe hat, in eine leere freie Zelle oder auf ihren Ablagestapel.
- Jede freie Zelle fasst eine Karte. Jede Karte darf in eine leere Spalte.
- Eine geordnete Reihe zieht auf einmal, wenn genug Platz ist, um sie Karte für Karte zu bewegen: so viele Karten wie leere freie Zellen plus eins, verdoppelt für jede leere Spalte (die Zielspalte nicht mitgezählt).
- Eine Karte auf einem Ablagestapel bleibt dort.
# Die Spiele
Die Spiele sind von 1 bis 32000 nummeriert, wie in anderen Fassungen dieses Spiels; jedes ist zu gewinnen, außer Spiel 11982.
# Das Ende der Partie
Du gewinnst, wenn alle Karten auf den Ablagestapeln liegen.
# Level und Sterne
3 Sterne: ohne Tipp und ohne Rücknahme.
