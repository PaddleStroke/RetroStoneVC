Amazonen
# Das Ziel
Sei der letzte Spieler, der noch ziehen kann. Hell beginnt.
# Ein Zug
Jeder Zug hat zwei Teile, beide von derselben Amazone ausgeführt:
- Ziehen: Eine deiner Amazonen zieht wie eine Dame im Schach, beliebig viele leere Felder entlang einer Reihe, einer Spalte oder einer Diagonale. Amazonen springen nie und schlagen nie.
- Schießen: Von dem Feld, auf dem sie gelandet ist, schießt die Amazone einen Pfeil, ebenfalls wie eine Dame, auf ein leeres Feld. Dieses Feld ist für den Rest der Partie verbrannt: Keine Amazone darf darauf stehen oder es überqueren, und kein Pfeil darf darüber fliegen.
- Der Pfeil darf auf das Feld zurückfliegen, das die Amazone gerade verlassen hat, oder darüber hinweg.
# Das Ende der Partie
Wer zu Beginn seines Zuges keine Amazone ziehen kann, verliert. Es gibt kein Remis.
