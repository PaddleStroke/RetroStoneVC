Vierzig Räuber
# Das Ziel
Alle 104 Karten aus zwei Kartenspielen auf die acht Ablagestapel bringen, zwei für jede Farbe, aufsteigend vom Ass bis zum König.
# Der Aufbau
- Zehn Spalten mit je vier Karten, alle offen.
- Die übrigen 64 Karten sind der Stapel.
# Karten bewegen
- Auf eine Spalte kommt eine Karte derselben Farbe, die einen Rang niedriger ist: die Kreuz 6 auf die Kreuz 7.
- Es zieht immer nur eine Karte, nie eine Reihe.
- Jede Karte darf eine leere Spalte füllen.
- Eine Karte auf einem Ablagestapel bleibt dort.
# Der Stapel
Tippe auf den Stapel, um eine Karte aufzudecken; die oberste gezogene Karte ist spielbar. Der Stapel wird nur einmal durchgespielt.
# Das Ende der Partie
Du gewinnst, wenn alle Karten auf den Ablagestapeln liegen. Nur wenige Spiele sind zu gewinnen.
