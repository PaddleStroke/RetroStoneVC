Dados mentirosos
# O objetivo
Ser o último jogador com dados. Cada um tem cinco dados sob um copo e só vê os seus. De 2 a 6 jogadores.
# Uma rodada
- Cada um rola os dados sob o seu copo.
- O primeiro jogador aposta: há pelo menos tantos dados mostrando tal face em toda a mesa.
- Na sua vez, cada jogador aumenta a aposta ou diz que a última é mentira.
- Aumentar é apostar mais dados (qualquer face), ou o mesmo número de dados com uma face maior.
- Os uns são curingas e contam como a face apostada; por isso só se aposta em faces de 2 a 6.
# O desafio
Todos os copos são levantados. Se os dados com a face apostada, mais os uns, chegarem pelo menos à aposta, quem desafiou perde um dado; se não, quem apostou perde um. Quem perdeu o dado começa a rodada seguinte, ou o próximo jogador, se quem perdeu estiver fora.
# O fim da partida
Quem fica sem dados está fora. Vence o último jogador com dados.
