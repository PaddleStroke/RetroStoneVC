法式塔罗
# 目标
共78张牌：四种花色各14张（10之上依次是侍从、骑士、皇后和国王），21张王牌，以及免牌（Excuse）。每一轮由庄家对抗其余所有玩家，即防守方。进行与玩家人数相同的轮数后（作废的轮不算），总分最高者获胜。
# 牌
- 三张关键牌（oudlers）是21、小一（Petit，即王牌1）和免牌。庄家赢得的关键牌越多，所需的分数就越少。
- 分值：关键牌或国王4.5分，皇后3.5分，骑士2.5分，侍从1.5分，其他牌0.5分：总共91分。
# 发牌
- 底牌（le chien）共6张（五人时3张）；三人时每人24张，四人时18张，五人时15张。
- 如果某位玩家唯一的王牌是小一，又没有免牌（孤小一，Petit sec），就亮出它，本轮作废。
# 叫牌
从发牌者的下家开始，每人只说一次：不叫，或者叫一个比之前所有叫牌都高的注。
- 小注（Petite）：庄家拿底牌。计一倍。
- 守注（Garde）：同上，计两倍。
- 无底守注（Garde sans）：谁也不看底牌；底牌归庄家。计四倍。
- 反底守注（Garde contre）：谁也不看底牌；底牌归防守方。计六倍。
如果所有人都不叫，由下家发牌。
# 五人局：叫国王
在处理底牌之前，庄家叫一张国王（如果四张国王都在自己手里，则叫一张皇后）。持有这张牌的人是庄家的秘密搭档，直到这张国王打出。如果这张牌在庄家自己手里，或者在底牌中，庄家就一个人打。
# 底牌
叫小注和守注时，底牌翻开给所有人看。庄家把底牌加入手牌，再扣下同样数量的牌：不能扣国王或关键牌，只有别无选择时才能扣王牌（扣下的王牌要亮出）。扣下的牌归庄家。
# 一墩
- 发牌者的下家领出第一墩；赢得一墩的人领出下一墩。
- 必须跟领出的花色。没有这种花色时，必须出王牌；王牌也没有，可以出任意一张牌。
- 墩中已有王牌时，能出更大的王牌就必须出；不能时，出一张较小的王牌。
- 最大的王牌赢得这一墩；没有王牌时，领出花色中最大的牌获胜。
- 免牌可以随时打出，但永远不会赢：持有者把它留在自己这边，作为交换给赢墩的人一张半分的牌。如果用它领出，则由下一张牌决定花色。如果在最后一墩打出，它归赢墩者，除非它所在的一方赢下了之前的每一墩：这时它赢得最后一墩。
# 亮王
在打出第一张牌之前，玩家可以亮出一次王牌：单亮王（poignée）10张（三人时13张，五人时8张），双亮王13张（15、10），三亮王15张（18、13）。免牌可以用来凑数。它为赢得本轮的一方带来20、30或40分。
# 计分
- 庄家一方没有关键牌时需要56分，有一张需要51分，两张41分，三张都有36分。
- 本轮的分值是25分加上所得分数与所需分数之差（半分按一分算），再按叫牌乘以1、2、4或6。
- 末墩小一（Petit au bout）：最后一墩里的小一值10分，乘以叫牌的倍数，归赢得这一墩的一方。
- 赢下所有墩的一方（大满贯，chelem；这里从不预先宣布）另得200分。
- 每位防守者向庄家支付本轮的分值，或者从庄家那里收取。五人局有搭档时，庄家得两份，搭档得一份。
