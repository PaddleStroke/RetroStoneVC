法式塔罗
# 目标
法国的塔罗纸牌游戏，共78张牌：四种花色各14张（10之上依次是侍从、骑士、皇后和国王），21张王牌，以及免牌（Excuse）。每一轮由一位玩家——庄家——对抗其余所有玩家，即防守方。一局的轮数等于玩家人数，总分最高者获胜。适合3、4或5人。
# 牌
- 三张关键牌（oudlers，又称bouts）是21、小一（Petit，即王牌1）和免牌。庄家赢得的关键牌越多，所需的分数就越少。
- 分值：关键牌或国王4.5分，皇后3.5分，骑士2.5分，侍从1.5分，其他牌0.5分。总共91分。
- 在牌桌上通常两张一组计分：国王或关键牌配一张小牌算5分，皇后配一张小牌算4分，骑士3分，侍从2分，两张小牌1分。结果相同。
# 发牌
- 两副牌之间不洗牌：像真正的牌桌上一样，把各墩牌收起来，切牌，再每次发三张。
- 从发牌者的下家开始，依次每次发三张。底牌（le chien）共6张（五人时3张），每次放一张，但绝不放最先或最后发的牌。
- 三人时每人24张，四人时18张，五人时15张。
- 如果某位玩家唯一的王牌是小一，又没有免牌（孤小一，Petit sec），就亮出它，本轮作废，由下家发牌。
# 叫牌
从发牌者的下家开始，每人只说一次：不叫，或者叫一个比之前所有叫牌都高的注。
- 小注（Petite）：庄家拿底牌。本轮计一倍。
- 守注（Garde）：同上，计两倍。
- 无底守注（Garde sans）：谁也不看底牌；底牌归庄家。计四倍。
- 反底守注（Garde contre）：谁也不看底牌；底牌归防守方。计六倍。
如果所有人都不叫，本轮作废，由下家发牌。
# 五人局：叫国王
在处理底牌之前，庄家叫一张国王（如果四张国王都在自己手里，则叫一张皇后）。持有这张牌的人成为庄家的搭档，但在这张国王打出之前要保密。如果这张牌在庄家自己手里，或者在底牌中，庄家就一个人对抗四人。
# 底牌
叫小注和守注时，底牌翻开给所有人看。然后庄家把底牌加入手牌，再秘密扣下同样数量的牌：不能扣国王或关键牌，只有别无选择时才能扣王牌。扣下的王牌要亮出。扣下的牌归庄家。
# 一墩
- 发牌者的下家领出第一墩；赢得一墩的人领出下一墩。
- 必须跟领出的花色。没有这种花色时，必须出王牌；王牌也没有，可以出任意一张牌。
- 墩中已有王牌时，能出更大的王牌就必须出；不能时，出一张较小的王牌。
- 最大的王牌赢得这一墩；没有王牌时，领出花色中最大的牌获胜。
- 免牌可以随时代替应出的牌打出，但永远不会赢：持有者把它留在自己这边，作为交换给赢墩的人一张半分的牌。如果用它领出，则由下一张牌决定花色。如果在最后一墩打出，它归赢墩者，除非它所在的一方赢下了之前的每一墩：这时它赢得最后一墩。
# 亮王
王牌多的玩家可以在打出第一张牌之前亮出王牌：单亮王（poignée）10张（三人时13张，五人时8张），双亮王13张（15、10），三亮王15张（18、13）。免牌可以用来凑数。它为赢得本轮的一方带来20、30或40分。
# 计分
- 庄家一方没有关键牌时需要56分，有一张需要51分，两张41分，三张都有36分。达到就赢下本轮，达不到就输。
- 本轮的分值是25分加上所得分数与所需分数之差（半分按一分算），再按叫牌乘以1、2、4或6。
- 末墩小一（Petit au bout）：最后一墩里的小一值10分，乘以叫牌的倍数，归赢得这一墩的一方。
- 赢下所有墩的一方（大满贯，chelem；这里从不预先宣布）另得200分。
- 每位防守者向庄家支付本轮的分值，或者从庄家那里收取。五人局有搭档时，庄家得两份，搭档得一份。所有人的分数总和始终为零。
# 对局结束
进行与玩家人数相同的轮数后（作废的轮不算），总分最高的玩家获胜。
# 在设备上玩
把设备轮流传递：轮到的玩家在下方看到自己的手牌，排成一行或两行。每位玩家的信息栏显示其总分、手牌数和叫牌。点按钮叫牌。墩放在中间，每张牌在出牌者那一侧，旁边是其棋子；刚赢下的那一墩留在原处，获胜的牌发光，直到下一墩领出第一张牌。点左上角的牌堆可以再看一次上一墩。底牌翻开时，所有人都能看到，而庄家的手牌保持背面朝上：把设备给大家看一圈，然后庄家点底牌拿起它，点要扣下的牌（再点一次可以拿回），再点圆形按钮。可以亮王时，顶部会出现一个显示王牌张数的按钮。每轮结束后，一张表格显示叫牌及其倍数、庄家一方赢得的关键牌、其得分、所需分数和差值、奖励分，然后是每位玩家的得分和总分；点它进入下一轮。悔棋只撤回你自己在本回合中的操作。
