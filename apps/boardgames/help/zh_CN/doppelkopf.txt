多佩尔科普夫
# 目标
德国最受欢迎的四人纸牌游戏，使用双副牌。每副牌中，持有梅花Q的两人为Re方，对抗另外两人，即Kontra方；但一开始谁也不知道谁和谁是一伙。一局由12副或24副牌组成，可以选择；最后总分最高者获胜。规则采用德国多佩尔科普夫联盟（DDV）的比赛规则。和这个游戏常见的打法一样，牌用法式花色；德式花色（橡果、树叶、红心、铃铛）以后可能会加入。4人轮流传递设备进行；谁也看不到别人的牌。
# 发牌
一副牌48张：每种花色的9、10、J、Q、K和A，每张各两张。每人12张。翡翠色先发牌；之后每副牌发牌者顺移一位。发牌者的下一位先表态，并领出第一墩。
# 保留
- 出第一张牌之前，每位玩家依次表态：正常（gesund，意为“健康”），或者有保留（Vorbehalt）。他想打什么要保密：单打，或者结婚。
- 持有两张梅花Q的玩家可以宣布结婚（Hochzeit）。这由他自己决定：他也可以不声张，暗中单打，对抗另外三人。
- 按顺序最先的单打优先；没有单打就打结婚；都没有就打普通局。
# 将牌
- 普通局中，红心10（Dulle）是最大的将牌。接下来是Q和J，各按梅花、黑桃、红心、方块的顺序，然后是方块A、10、K、9：共26张将牌。
- 其他花色从大到小为A、10、K、9；红心只有A、K、9。
- 一墩中有两张相同的牌时，先出的那张大。
# 阵营
- 持有梅花Q（die Alten，“老家伙”）的玩家是Re方，其他人是Kontra方。每人知道自己属于哪一方，但不知道别人的。有人打出梅花Q或宣报时，阵营就会显露。
- 结婚：前三墩中，第一个被新娘以外的玩家赢走的墩，决定该玩家成为新娘的搭档。如果新娘三墩全赢，她就独自对抗三人，按单打计算。
# 单打
一名玩家，即单打者（Re），对抗另外三人（Kontra）。
- Q单打：只有八张Q是将牌。
- J单打：只有八张J是将牌。
- 花色单打：使用普通局的将牌，但以所选花色代替方块。
- 素局（Fleischlos，意为“无肉”）：没有将牌；每种花色从大到小为A、10、K、Q、J、9。
# 出牌
能跟领出的花色就必须跟（所有将牌算作同一花色）；否则可以出任意一张牌。最大的将牌赢得这一墩；没有将牌时，领出花色中最大的牌赢。赢家领出下一墩。
# 宣报
- 出牌之前，玩家可以为本方宣报：手中至少有11张牌时可报Re或Kontra，至少10张时可报“不到90”（keine 90），至少9张时可报“不到60”，至少8张时可报“不到30”，至少7张时可报schwarz（“黑”，即一墩不得）。每个宣报都包含比它低的宣报。
- 对方宣报之后，仍可以用Re或Kontra回应，期限比对方那个宣报自身的期限晚一张牌。
- 结婚时，找到搭档之前不能宣报；之后的期限顺延找搭档所用的墩数。
- 在这里，玩家在轮到自己、设备在自己手中时宣报。
# 输赢
- 牌分：A 11分，10 10分，K 4分，Q 3分，J 2分，共240分。
- Re方得121分获胜，Kontra方得120分获胜。如果只有Kontra报过，Re方得120分即获胜，Kontra方需要121分。
- 报了“不到90”（“不到60”“不到30”、schwarz）的一方，必须让对方少于90分（少于60分、少于30分、一墩不得），否则对方获胜。如果双方的这类宣报都失败，则无人获胜。
# 玩法分值
- 获胜：1分。输方不到90分、不到60分、不到30分、一墩不得（schwarz）：各1分。
- 报了Re：2分。报了Kontra：2分。每个报出的“不到90”“不到60”“不到30”和schwarz：各1分。
- 对方报“不到90”而本方达到120分，对“不到60”达到90分，对“不到30”达到60分，对schwarz达到30分：各1分。
- 额外分（Sonderpunkte），只在普通局和结婚中计算，归做到的一方：抓到狐狸（Fuchs：自己赢的墩里有对方的方块A）、Doppelkopf（40分或以上的一墩）、Karlchen（“小卡尔”：用梅花J赢下最后一墩），以及战胜老家伙（gegen die Alten：Kontra方获胜）：各1分。双方的额外分互相抵消。
# 计分
- 普通局：Re方获胜时，Re方每人得玩法分值（Kontra方获胜时为负分），加上Re方的额外分，减去Kontra方的额外分；Kontra方每人得相反的分数。
- 单打：单打者得三倍，每个对手得一倍。
- 这里没有强制单打。
# 游戏结束
列表中最后一副牌打完后，总分最高者获胜。总分相同则共同获胜。
# 在设备上玩
把设备交给棋子发光的玩家；他点开始后看到自己的手牌。要表态“正常”，点“不叫”。要保留，先点一种玩法，再点对勾（或再点一次同一玩法）：花色单打（该花色的标志）、Q单打（一张Q）、J单打（一个主教，即J的人像）、素局（四张A），或结婚（两张梅花Q，只有两张都在你手里时才有）。每个座位显示该玩家的表态：“不叫”标记表示正常，灯表示保留。出牌期间，每个座位显示全桌已知的信息：梅花Q表示Re，被划掉的梅花Q表示Kontra，宣报后发出金光；你自己的阵营总是显示在你的座位上。单打者的座位显示单打，新娘的座位在找到搭档前显示结婚；“不到90”“不到60”“不到30”和schwarz显示为深色圆盘里的90、60、30和0。可以宣报时，牌堆对面的按钮显示你的下一个宣报：在出牌之前点它。出牌时，点一张发光的牌让它升起，再点它一次或点中央它的位置；也可以把它拖过去。点右下角的牌堆可查看上一墩。每副牌结束后，一张表显示：各方的牌分、宣报、额外分（方块A：狐狸；40：Doppelkopf；梅花J：Karlchen；被划掉的Q：战胜老家伙），获胜方有金色对勾；然后是玩法分值、额外分的差额和Re方每人的得分（单打者乘以3）；每位玩家的得分和总分；以及各副牌的列表，获胜者的筹码发出金光。点它开始下一副。每个信息栏显示手牌数和总分。撤销可收回尚未确认的选择，但设备交出后不能收回。
