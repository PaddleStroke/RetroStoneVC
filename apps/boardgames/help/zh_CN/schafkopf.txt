沙夫科普夫
# 目标
巴伐利亚最有名的四人纸牌游戏。每副牌中，叫牌胜出的玩家，即庄家，与他叫出的搭档一起，或者独自一人，对抗其他玩家；输赢按分值表以分数结算。一局由12副牌组成；最后总分最高者获胜。规则采用巴伐利亚规则。4人轮流传递设备进行；谁也看不到别人的牌。
# 牌
一副牌32张，从7到A。沙夫科普夫本来用德式花色；这里用法式花色，这种牌在这个游戏中也很常用：梅花代替橡果（Eichel），黑桃代替树叶（Gras），红心代替红心（Herz），方块代替铃铛（Schellen）。Q称为Ober（“上人”），J称为Unter（“下人”），A称为Sau（“母猪”）。德式花色以后可能会加入。
# 发牌
每人8张。翡翠色先发牌；之后每副牌发牌者顺移一位。发牌者的下一位先表态，并领出第一墩。
# 叫牌
- 每位玩家依次不叫（weiter，意为“过”），或者表示要打，并秘密选择玩法：Rufspiel（“叫A局”）、Wenz（只有Unter作将牌的局）或Solo（单打）。
- Rufspiel：他叫出某种花色（梅花、黑桃或方块，不能是红心）的A（Sau），他手中必须有这种花色的牌，但没有这张A。持有这张A的玩家就是他的搭档，这张A打出之前谁也不知道是谁。
- Wenz和Solo：他独自对抗另外三人。
- 打最高的玩法：Solo，其次Wenz，再次Rufspiel；玩法相同时先表态者优先。如果所有人都不叫，就作废重发；如果选择了Ramsch（“杂烩”），就打Ramsch。
# 将牌
- Rufspiel：四张Ober（梅花、黑桃、红心、方块）是最大的将牌，然后是四张Unter，顺序相同，然后是红心A、10、K、9、8、7。共14张将牌。
- Solo：同上，但以所选花色代替红心。
- Wenz：只有四张Unter是将牌。
- 其他花色从大到小为A、10、K、（Ober）、（Unter）、9、8、7。
# 出牌
- 能跟领出的花色就必须跟（所有将牌算作同一花色）；否则可以出任意一张牌。最大的将牌赢得这一墩；没有将牌时，领出花色中最大的牌赢。赢家领出下一墩。
- 被叫的A：这种花色第一次被领出时，持有者必须打出这张A。在此之前，他不能在别的花色上垫掉这张A，领出这种花色时也只能出这张A；除非他有这种花色四张或更多：那样他可以用另一张领出，即“逃跑”（davonlaufen）。最后一墩可以随便出。
# 输赢
- 牌分：A 11分，10 10分，K 4分，Ober 3分，Unter 2分，共120分。
- 庄家和他的搭档（或单打者）得61分或以上获胜。
- Schneider：输方只得30分或更少。Schwarz（“黑”）：输方一墩未赢。
# 分值表
- Rufspiel 10分；Solo和Wenz 50分。
- Schneider再加10分，Schwarz再加10分。
- Laufende（“连将”）：从梅花Ober往下（Wenz中从梅花Unter往下）连续不断的最大将牌，由某一方（无论庄家一方还是另一方）全部持有时，从3张起（Wenz中从2张起）每张10分。
- Rufspiel：每个赢家得这个分值，每个输家失去这个分值。Solo和Wenz：单打者得到或失去三倍分值，其他玩家各一倍。
- 这里不采用：加倍（Kontra、Re）、Tout、Sie及其他地方玩法。
# Ramsch
所有人都不叫且选择了Ramsch时，各自为战，将牌与Rufspiel相同。牌分最多的玩家付给其他每人10分；牌分相同时，墩数多的人付；仍相同，则这几人都付。赢下所有墩（Durchmarsch，“通吃”）可从每人那里赢得50分。
# 对局结束
第12副牌打完后，总分最高者获胜。总分相同则共同获胜。
# 在设备上玩
把设备交给棋子发光的玩家；他点开始后看到自己的手牌。叫牌时先点一种玩法，再点对勾（或再点一次同一玩法）：Rufspiel点三张A之一（不能叫的A呈灰色），Wenz点主教（Unter的人像），Solo点该花色的标志；要不叫，点“不叫”。每个座位显示该玩家的表态：“不叫”标记，或想打的玩家显示对勾。出牌期间，庄家的座位显示他的玩法：所叫的A、Wenz或Solo的花色；被叫的A打出后，搭档的座位也会显示它。出牌时，点一张发光的牌让它升起，再点它一次或点中央它的位置；也可以把它拖过去。点右下角的牌堆可查看上一墩。每副牌结束后，一张表显示：庄家一方的玩法和牌分（金色对勾：赢），90表示Schneider，120表示Schwarz；梅花Ober（Wenz中为梅花Unter）及计入的Laufende、分值表的分数（单打者乘以3）和最终分值；Ramsch中显示每位玩家的牌分，付分者为红色。然后是每位玩家的得分和总分，以及各副牌的列表，玩家赢时其筹码为金色。点它开始下一副。每个信息栏显示手牌数和总分。撤销可收回尚未确认的选择，但设备交出后不能收回。
