逻辑门
# 目标
一块电路板：开关上面是逻辑门，最上方是灯；每个开关都位于它所连接的门的正下方。每根导线把信号向上传送，信号是0（暗）或1（发出金光）。设置开关，让所有的灯都亮起来，同时红色的警报灯必须保持熄灭。共6章，165关。随机生成的电路要先选大小：小（3到4个开关）、中（5到6个）或大（7到8个），再点按它可以用的部件，让它们亮起或变暗：每种门、红色警报灯、两盏灯、分路开关、锁住的开关和跳线；然后点按开始。
# 逻辑门
每个门都是镶在胡桃木牌上的黄铜图形：输入从下方进入，输出从上方离开。门顶上的小圆圈表示把结果取反。下面列出每种情况的输入和输出：01 → 1 表示第一个输入为0、第二个输入为1时，输出为1。门上刻着它的英文名称，和电路图上一样：NOT、AND、OR、XOR、NAND 或 NOR。
- 非门（NOT）：尖端带小圆圈的三角形，输出与输入相反。0 → 1，1 → 0。
- 与门（AND）：底部平直、顶部圆拱的圆顶形，所有输入都为1时才输出1。00 → 0，01 → 0，10 → 0，11 → 1。
- 或门（OR）：顶端尖、底部内凹的盾形，只要有一个输入为1就输出1。00 → 0，01 → 1，10 → 1，11 → 1。
- 异或门（XOR）：或门的形状，下面多一条弧线，两个输入不同时输出1。00 → 0，01 → 1，10 → 1，11 → 0。
- 与非门（NAND）：带小圆圈的与门圆顶。00 → 1，01 → 1，10 → 1，11 → 0。
- 或非门（NOR）：带小圆圈的或门盾形。00 → 1，01 → 0，10 → 0，11 → 0。
后面的关卡里有三个输入的门：与门、或门、与非门和或非门的规则不变；异或门在为1的输入个数是奇数时输出1。
# 分路开关
导线在这块木牌上分成左右两路。信号沿黄铜轨道所指的方向前进，另一路为0。点一下分路开关，信号就改走另一路。
# 可剪断的导线
有些导线是跳线：在两个黄铜接线柱之间拱起的彩色导线。点一下跳线就能剪断它：跳线断成两截，断口之后的导线变为0，就像断开了一样。剪断后无法接回，只能撤销（跳线会重新接上）或者重新开始这一关。有些关卡允许剪断的次数少于跳线的数量，信息栏会显示你还能剪几次。
# 锁定的开关
上面拧着黄铜压条的开关不能拨动。
# 关卡与星星
各章依次引入新的门，每章的开关都从几个逐渐增加到8个：1 与门和或门，加上警报灯，从本章中段起出现非门（40关）；2 异或门和锁定的开关；3 与非门和分路开关；4 或非门和可剪断的导线；5 三输入的门、一个开关连接多个门、两盏灯；6 综合一切的大电路。各章标签页后面的骰子标签页，会按上面说的选择随机生成一个新电路。
拨动一次开关或剪断一根导线算一步。每关都有标准步数，即解开它所需的最少步数。按标准步数解开得3颗星；最多多两步得2颗星；否则得1颗星。用了提示最多得2颗星。撤销撤回一步，这一步不再计数。已解开的关卡始终开放，尚未解开的前三关也开放。
# 在设备上玩
- 关卡表：每章一个标签页，下面是这一章的关卡：已解开的为金色并带有星星，开放的为木色，锁住的为深色木头。点一个关卡开始游戏。你获得的星星会保存在设备上。
- 点开关拨动它，点分路开关转向，点跳线剪断它。变化会沿着导线一个门一个门地向上传递。
- 电路板旁边：章节和关卡编号；圆形箭头重新开始这一关；灯泡按钮给出提示：下一个要改动的部件会闪烁。如果闪烁的是重新开始按钮，说明剪错了线：请先撤销。
- 在随机电路中，提示旁边的门形按钮会回到大小和部件的选择；下一个按钮用同样的选择生成新电路。如果开始按钮一直是暗的，就点亮一个正在柔和发光的门：谜题需要与门，或者非门加上或门、与非门、或非门之一。
- 所有灯都亮起时，它们会迸发金光，随后显示你获得的星星和进入下一关的按钮。新对局（格子按钮）会回到关卡表。
- 信息栏在开关图标旁显示你的步数，在跳线旁显示剩余的剪断次数，在星星旁显示标准步数。在宽屏上，层数多的电路可能会横过来摆放：开关在左，灯在右。
