逻辑门
# 目标
一块电路板：下方是开关，开关上面是逻辑门，最上方是灯。每根导线把信号向上传送，信号是0（暗）或1（发出金光）。设置开关，让所有的灯都亮起来，同时红色的警报灯必须保持熄灭。共6章，150关。
# 逻辑门
每个门都是镶在胡桃木牌上的黄铜图形：输入从下方进入，输出从上方离开。门顶上的小圆圈表示把结果取反。下面列出每种情况的输入和输出：01 → 1 表示第一个输入为0、第二个输入为1时，输出为1。
- 非门（NOT）：尖端带小圆圈的三角形，输出与输入相反。0 → 1，1 → 0。
- 与门（AND）：底部平直、顶部圆拱的圆顶形，所有输入都为1时才输出1。00 → 0，01 → 0，10 → 0，11 → 1。
- 或门（OR）：顶端尖、底部内凹的盾形，只要有一个输入为1就输出1。00 → 0，01 → 1，10 → 1，11 → 1。
- 异或门（XOR）：或门的形状，下面多一条弧线，两个输入不同时输出1。00 → 0，01 → 1，10 → 1，11 → 0。
- 与非门（NAND）：带小圆圈的与门圆顶。00 → 1，01 → 1，10 → 1，11 → 0。
- 或非门（NOR）：带小圆圈的或门盾形。00 → 1，01 → 0，10 → 0，11 → 0。
后面的关卡里有三个输入的门：与门、或门、与非门和或非门的规则不变；异或门在为1的输入个数是奇数时输出1。
# 分路开关
导线在这块木牌上分成左右两路。信号沿黄铜轨道所指的方向前进，另一路为0。点一下分路开关，信号就改走另一路。
# 可剪断的导线
有些导线上装着奶油色的小保险丝。点保险丝就能剪断导线：火花四溅，保险丝之后的导线变为0，就像断开了一样。剪断后无法接回，只能悔棋或者重新开始这一关。有些关卡允许剪断的次数少于保险丝的数量，横栏会显示你还能剪几次。
# 锁定的开关
上面拧着黄铜压条的开关不能拨动。
# 关卡与星星
各章内容：1 非门、与门、或门；2 异或门、与非门、或非门；3 分路开关；4 可剪断的导线；5 更长的链条、一个开关连接多个门、三输入的门；6 综合一切的大电路。
拨动一次开关或剪断一根导线算一步。每关都有标准步数，即解开它所需的最少步数。按标准步数解开得3颗星；最多多两步得2颗星；否则得1颗星。使用提示后，这一关最多得2颗星。悔棋撤回一步，这一步不再计数。已解开的关卡始终开放，尚未解开的前三关也开放。
# 在设备上玩
- 关卡表：每章一个标签页，下面是这一章的关卡：已解开的为金色并带有星星，开放的为木色，锁住的为深色木头。点一个关卡开始游戏。
- 点开关拨动它，点分路开关转向，点保险丝剪断它所在的导线。变化会沿着导线一个门一个门地向上传递。
- 电路板旁边：格子按钮返回关卡表；接着是章节和关卡编号；圆形箭头重新开始这一关；灯泡按钮给出提示：下一个要改动的部件会闪烁。如果闪烁的是重新开始按钮，说明剪错了线：请先悔棋。
- 所有灯都亮起时，它们会迸发金光。点电路板进入下一关。新对局也会回到关卡表。
- 横栏显示你的步数、剩余的剪断次数，右端在三颗星旁边显示标准步数。
