国际象棋
# 目标
将死对方的王：攻击它，让它无处可逃。白方先走。
# 棋子的走法
- 王：向任意方向走一格。后：沿横线、竖线或斜线走，格数不限。车：沿横线或竖线走。象：沿斜线走。
- 马：走“L”形，即朝一个方向走两格，再向旁边走一格。它是唯一可以越过其他棋子的棋子。
- 兵：向前走一格，从起始格出发时也可以走两格。吃子时斜向前走一格。
- 棋子走到对方棋子所在的格子就能吃掉它。
# 特殊走法
- 王车易位：王朝一个车的方向走两格，车跳到王越过的那一格。只有在两者都还没有动过、中间没有棋子，并且王没有被将军、不经过受攻击的格子、走完后也不处于被将军状态时，才可以这样走。
- 吃过路兵：一个兵刚走了两格并停在对方兵的旁边时，对方的兵可以把它当作只走了一格那样吃掉，但只能在紧接着的下一步进行。
- 升变：兵走到底线时，变成后、车、象或马。
# 将军与对局结束
你永远不能走出让自己的王处于被将军（受到攻击）状态的棋。
- 将死：王被将军，而且没有任何走法能解救它。该玩家输棋。
- 和棋：逼和（没有合法的走法，但没有被将军）、剩下的棋子太少无法将死、同一局面第三次出现，或者双方各走五十步都没有吃子也没有走兵。
# 国际象棋960
底线棋子的开局摆法是随机的，两个象在不同颜色的格子上，王在两个车之间。王车易位后王和车所在的格子与普通国际象棋相同（王到g、车到f，或者王到c、车到d），而且它们经过或到达的每个格子（除它们两个以外）都必须是空的。要进行王车易位，就把王走到与它易位的车上。
# 疯狂屋象棋
吃掉的棋子会换到你这一方，成为你的备用子。你可以不走棋，而把一个备用子放到任意空格上，甚至可以借此将军或将死。兵不能放在第一横排或最后一横排。升变来的棋子被吃掉后作为兵回来。没有因子力不足而和棋的情况。
# 三次将军
先将军三次的一方获胜。将死也获胜。
# 山丘之王
王先走到中央四格之一的一方获胜。将死也获胜。
# 反象棋
目标是失去自己所有的棋子：当你没有棋子了，或者无棋可走时，你就赢了。
- 吃子是强制的，但可以选择吃哪一个。
- 王是普通的棋子：没有将军，王可以被吃掉，也没有王车易位。兵也可以升变为王。
- 只剩下象，并且双方的象分别在不同颜色的格子上：和棋。
# 原子象棋
每次吃子都会爆炸：被吃的棋子、吃子的棋子，以及周围八格中除兵以外的所有棋子都会离开棋盘。
- 炸掉对方的王就获胜，即使自己的王正被将军也一样。将死也能获胜。
- 王不能吃子，任何着法都不能炸掉自己的王。两个王相邻时，谁都不算被将军。
- 双方都没有足够的棋子取胜时，对局为和棋。
# 国王赛跑
没有兵，任何着法都不能将军。最先到达最后一行的王获胜；如果白王先到，而黑王在紧接着的下一步也到达，对局为和棋。
# 部落象棋
白方有36个兵，没有王，所以永远不会被将军。白方将死黑王即获胜，黑方吃掉所有白方棋子即获胜。第一行的白兵也可以前进两格（这时不能被吃过路兵）。
