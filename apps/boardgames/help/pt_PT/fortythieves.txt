Quarenta Ladrões
# O objetivo
Levar as 104 cartas de dois baralhos para as oito fundações, duas por naipe, do ás ao rei.
# A disposição
- Dez colunas de quatro cartas, todas voltadas para cima.
- As outras 64 cartas formam o baralho.
# Mover as cartas
- Numa coluna, põe uma carta de um valor abaixo e do mesmo naipe: o 6 de paus sobre o 7 de paus.
- Só se move uma carta de cada vez, nunca uma sequência.
- Qualquer carta pode ocupar uma coluna vazia.
- Uma carta numa fundação fica lá.
# O baralho
Toca no baralho para virar uma carta para o descarte; a carta de cima do descarte pode ser jogada. O baralho só se percorre uma vez.
# O fim do jogo
Ganhas quando todas as cartas estão nas fundações. Poucas distribuições se podem ganhar.
