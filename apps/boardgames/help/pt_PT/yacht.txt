Yacht
# O objetivo
Faz o máximo de pontos preenchendo todas as linhas da tua coluna com lançamentos de cinco dados. De um a seis jogadores; sozinho, tenta chegar aos 200 pontos (Generala: 150).
# A tua vez
- Lança os cinco dados até três vezes, guardando os dados que quiseres entre lançamentos.
- Depois regista-os numa linha vazia. Se não servirem para nenhuma linha, tens mesmo assim de escolher uma: vale 0.
# A folha de pontuação
Cada linha é um desenho de dados.
- Um dado (de um a seis): a soma dos dados que mostram essa face.
- A estrela: um bónus por 63 ou mais nas linhas de um a seis: 35 (Clássico), 50 (Nórdico).
- Dois dados sobrepostos (Nórdico): um par, a soma do par. Dois pares (Nórdico): a soma dos dois.
- Três dados sobrepostos: três iguais. Clássico: a soma dos cinco dados. Nórdico: a soma dos três.
- Quatro dados sobrepostos: quatro iguais. Clássico: a soma dos cinco. Nórdico: a soma dos quatro. Generala (póquer): 40.
- Três dados e dois dados: um full house. Clássico: 25. Nórdico: a soma dos dados. Generala: 30.
- Quatro dados pequenos em fila (Clássico): quatro seguidos, 30.
- Cinco dados pequenos em fila: uma sequência. Clássico: 40. Nórdico: 1-2-3-4-5, 15; 2-3-4-5-6, 20. Generala: 1-2-3-4-5, 2-3-4-5-6 ou 3-4-5-6-1: 20.
- Dados lançados para todos os lados: a sorte, a soma dos dados.
- Cinco dados iguais: cinco iguais, 50. Com uma estrela (Clássico): os cinco iguais a mais, 100 cada um.
- Duas linhas de cinco iguais (Generala): a generala dupla, 100.
# Clássico: outros cinco iguais
Quando a linha de cinco iguais tem 50, cada novo cinco iguais vale mais 100. Depois de essa linha estar preenchida, um cinco iguais é um joker: vai para a linha da sua face, se estiver vazia; senão, para qualquer linha vazia abaixo da estrela, onde o full house e as sequências valem por inteiro; senão, para uma linha de um a seis, por 0.
# Generala
Uma sequência, um full house ou um póquer no primeiro lançamento («servidos») valem mais 5. Uma generala servida ganha logo. A generala dupla só vale 100 se a linha de generala tiver 50; caso contrário, vale 0. Não há bónus para as linhas de um a seis.
# O fim do jogo
Quando todas as linhas estiverem preenchidas, ganha o total mais alto; os totais iguais partilham a vitória.
