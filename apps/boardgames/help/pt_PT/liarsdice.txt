Dados mentirosos
# O objetivo
Ser o último jogador com dados. Cada um tem cinco dados debaixo de um copo e só vê os seus. De 2 a 6 jogadores.
# Uma ronda
- Cada um lança os dados debaixo do seu copo.
- O primeiro jogador aposta: há pelo menos tantos dados em toda a mesa a mostrar tal face.
- Na sua vez, cada jogador sobe a aposta ou diz que a última é mentira.
- Subir é apostar mais dados (qualquer face), ou o mesmo número de dados com uma face mais alta.
- Os uns são jokers e contam como a face apostada; por isso só se aposta em faces de 2 a 6.
# O desafio
Todos os copos são levantados. Se os dados com a face apostada, mais os uns, forem pelo menos tantos como a aposta, quem desafiou perde um dado; se não, perde quem apostou. Quem perdeu começa a ronda seguinte, ou o jogador seguinte, se quem perdeu tiver sido eliminado.
# O fim do jogo
Quem fica sem dados é eliminado. Ganha o último jogador com dados.
