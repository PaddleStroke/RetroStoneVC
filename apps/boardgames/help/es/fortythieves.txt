Cuarenta ladrones
# El objetivo
Llevar las 104 cartas de dos barajas a las ocho bases, dos por palo, del as al rey.
# La disposición
- Diez columnas de cuatro cartas, todas boca arriba.
- Las otras 64 cartas forman el mazo.
# Mover cartas
- Sobre una columna se pone una carta de un valor menos y del mismo palo: el 6 de tréboles sobre el 7 de tréboles.
- Solo se mueve una carta a la vez, nunca una escalera.
- Cualquier carta puede ocupar una columna vacía.
- Una carta en una base se queda allí.
# El mazo
Toca el mazo para pasar una carta al descarte; la carta de arriba del descarte se puede jugar. El mazo se recorre una sola vez.
# El final de la partida
Ganas cuando todas las cartas están en las bases. Pocos repartos se pueden ganar.
