カナスタ
# 目的
先に5000点に達したチームの勝ちです。4人で2組のペアになって遊びます（ペアは向かい合って座り、出したメルドを共有します）。2人でも遊べます。同じ数のカードを出し、7枚のカナスタを作って、上がりましょう。
# カード
- 52枚のトランプ2組とジョーカー4枚、合わせて108枚。
- ジョーカーと2はワイルドカードです。メルドの中でどの数の代わりにもなります。
- カードの点：ジョーカー50、エースと2は20、キングから8は10、7から4は5、黒の3は5。
- 赤の3はボーナスカードです。配られたり引いたりした赤の3はすぐに自分のチームのメルドの横に出し、代わりにもう1枚引きます。1枚100点、4枚そろえば800点です。手の終わりに何も出していないチームでは、マイナスになります。
- 黒の3は捨て札の山をふさぎます。いちばん上に黒の3があるあいだは、誰も山を取れません。
# 配り方
- 各自11枚（2人なら15枚）。次の1枚で捨て札の山を始め、残りは山札です。そのカードがワイルドカードか赤の3なら、別のカードでふたをし、捨て札の山は凍結されます。
- 配り手は手ごとに次の人へ移ります。
# 手番
- 山札のいちばん上を1枚引きます（2人なら2枚）。または捨て札の山を全部取ります。
- 好きならメルドを出します。
- 1枚を表向きに捨てると、手番は終わりです。
# メルドとカナスタ
- メルド：同じ数のカード3枚以上（エース、4からキング）。そのうちナチュラルが2枚以上、ワイルドは3枚まで。チームは各数につきメルドを1つだけ持ち、同じ数のカードはそこに加えます。
- カナスタ：7枚以上のメルド。ナチュラル（ワイルドなし）は500点、ミックスは300点。
- 最初のメルド：チームが初めて出すメルドは、1回の手番で出し、カードの点の合計がチームの得点1500未満なら50以上、1500以上なら90以上、3000以上なら120以上、マイナスのあいだは15以上でなければなりません。捨て札の山をいっしょに取るために、引く前に出してもかまいません。
# 捨て札の山
- 山を取るには、いちばん上のカードをすぐにメルドに入れます。手札のカードといっしょに出すか、チームのメルドに加えます。そのあと山の残りを手札に加えます。
- 山の中にワイルドカード（横向き）があるあいだ、そしてまだメルドを出していないチームにとって、山は凍結されています。そのときは、いちばん上と同じ数のナチュラルのペアを手札から出さないと取れません。
- いちばん上が黒の3かワイルドカードのときは、決して取れません。
# 上がり
- 最後の1枚がなくなれば上がりです。全部を出すか、1枚を残して出し、それを捨てます。チームにカナスタがあるとき（2人なら2つ）だけです。それまでは、手札が2枚未満になるようには出せません。
- 黒の3は上がるときだけ出せます（3枚か4枚、ワイルドなし）。
- 上がりは100点。隠し上がりは200点です。山札から引いたあと、その手で一度も出さずに、手札全部を1回の手番で出すことです。このときは最初のメルドの点の条件はありません。
- 山札がなくなったら、捨て札の山のいちばん上をチームのメルドに加えられる人は、山を取らなければなりません。取れなければ、その手は終わりです。
# 得点
手の終わりに、各チームは出したカード、カナスタ、赤の3、上がりの点を得て、仲間の手札に残ったカードの点を引きます。
# ゲームの終わり
どちらかのチームが5000点に達した手で、ゲームは終わります。合計の多いほうの勝ち。同点なら勝ちを分け合います。
# 端末での遊び方
手札は秘密です。画面が求めたら端末を渡し、次のプレイヤーがスタートボタンをタップします。自分の手札は下に、数の順に並びます。ほかの手札は上の小さな扇形です。自分のチームのメルドは手札の上に、相手チームのものは扇形の下に、数ごとに1列ずつ並びます。カナスタは山にまとまり、下に枚数が出ます。ナチュラルなら金色の光に包まれ、ミックスなら下にワイルドカードが横向きに見えます。各チームのコマと赤の3は列の左にあります。まだメルドを出していないチームには、右の暗い円に最初のメルドに必要な点が、その横にこの手番で出した点が表示されます。各バーには手札の枚数とチームの得点が出ます。
- 山札をタップすると引きます。
- 手札のカードをタップして選びます。もう一度タップすると戻します。
- それから自分のチームのメルドをタップして加えるか、チームの列をタップして新しいメルドを作ります。引く前なら、捨て札の山をタップすると選んだカードといっしょに山を取ります。引いたあとは、1枚を選んで捨て札の山をタップすると捨てます。カードをドラッグしてもかまいません。
- 選んだカードでできることが光ります：捨て札の山、メルド、空いた場所。
- 山札が空で山を取れないときは、空の山札をタップするとその手が終わります。
- 手の終わりには、各チームの出したカード、カナスタ、赤の3、上がり、手札に残ったカード、その手の点、合計が表に出ます。タップすると次の手です。
元に戻すでは、端末を渡したところまで自分の操作を取り消せます。
