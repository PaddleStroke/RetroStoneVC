チェッカー
# 目的
相手の駒をすべて取るか、相手が動けないようにしましょう。駒は暗い色のマスに置かれ、斜めに動きます（トルコルールを除く）。
# 国際ルール（10×10）
- 明るい色が先手です。普通の駒は斜め前へ1マス進み、隣にある相手の駒を飛び越えて、そのすぐ先の空いたマスに着地することで、前にも後ろにも駒を取ります。
- 取ることは義務です：できるだけ多くの駒を取る手を選び、同じ手の中で続けて飛び越えます。取った駒は手の終わりに盤から取り除きます。同じ駒を2回飛び越えることはできません。
- いちばん奥の段で手を終えた普通の駒はキングになります。キングは斜めに何マスでも動けて、離れたところからも駒を取れます。取った駒の先の空いたマスなら、どこにでも着地できます。
- 引き分け：同じ局面が3回目に現れたとき、またはキングだけを動かし駒を取らない手がお互い25手ずつ続いたとき。
# 英国ルール（8×8）
- 暗い色が先手です。普通の駒は前にしか進めず、前にしか取れません。キングは斜めのどの方向にも1マス動けて、取るときも同じです。
- 取ることは義務ですが、どの取り方をするかは選べます。一度飛び越え始めたら、取れる駒はすべて取らなければなりません。キングになったら、その手はそこで終わります。
- 引き分け：同じ局面が3回目に現れたとき、または駒を取らず普通の駒も動かさない手がお互い40手ずつ続いたとき。
# ロシアルール（8×8）
- 国際ルールと同じですが、どの取り方をするかは選べます。一度飛び越え始めたら、取れる駒はすべて取らなければなりません。
- 取ったあと、さらに取り続けられるマスがあれば、キングはそのマスに着地しなければなりません。
- いちばん奥の段に着いた普通の駒は、取っている途中でもすぐにキングになり、そのままキングとして取り続けます。
- 引き分け：同じ局面が3回目に現れたとき、またはキングだけを動かし駒を取らない手がお互い15手ずつ続いたとき。
# ブラジルルール（8×8）
国際ルールを8×8の盤で遊びます。引き分け：同じ局面が3回目に現れたとき、またはキングだけを動かし駒を取らない手がお互い20手ずつ続いたとき。
# トルコルール（8×8）
- 64マスすべてを使います。各プレイヤーは、自分の側の2段目と3段目に16個の普通の駒を並べて始めます。明るい色が先手です。
- 普通の駒はまっすぐ前か横へ1マス進み、取るときも同じです。キングは縦か横に何マスでも動けて、離れたところからも駒を取れます。
- 取ることは義務です：できるだけ多くの駒を取る手を選びます。取った駒はその場ですぐに取り除き、取る駒は来た方向へまっすぐ引き返すことはできません。
- 引き分け：同じ局面が3回目に現れたとき、または駒を取らず普通の駒も動かさない手がお互い25手ずつ続いたとき。
# フリジアンルール（10×10）
- 国際ルールですが、普通の駒もキングも、横と縦にまっすぐ取ることもできます。2マス先にある相手の駒を飛び越えて、そのすぐ先の暗いマスに着地します。キングは8方向すべてに離れたところから取れます。
- いちばん価値の高い駒を取らなければなりません：キングは普通の駒1つより価値が高く、2つより低いものとします。キングと普通の駒が同じ価値を取れるときは、キングで取らなければなりません。
- 普通の駒が残っているあいだは、同じキングを取らずに3回より多く続けて動かすことはできません。
- 引き分け：キング2つ対1つで双方が7手ずつ指したとき、キング1つ対1つで双方が2手ずつ指したとき、または同じ局面が3回目に現れたとき。
# カナダルール（12×12）
12×12の盤で、各30個の駒を使う国際ルールです。
# バシュニ（8×8）
ロシアルールと同じですが、取った駒はゲームに残ります。
- 取るときは、飛び越えた塔のいちばん上の駒だけを取り、手の終わりに取った側の塔の下に入れます。下に残った駒はその場にとどまり、新しくいちばん上になった駒に従います。
- 塔はいちばん上の駒の持ち主のもので、その駒と同じように動きます。キングになるのはいちばん上の駒だけです。1回の取りで同じ塔を飛び越えられるのは1度だけです。
- 動かせないプレイヤーは、相手の塔の下に駒があっても負けです。引き分けはロシアルールと同じです。
# ゲームの終わり
駒がなくなったプレイヤー、または動けなくなったプレイヤーの負けです。
