チェス
# 目的
相手のキングをチェックメイトしましょう。つまり、逃げ場がないようにキングを攻撃します。白が先手で、その後は1手ずつ交互に指します。
# 駒の動き
- キング：どの方向にも1マス。
- クイーン：縦・横・斜めのまっすぐな線上を何マスでも。
- ルーク：縦か横に何マスでも。
- ビショップ：斜めに何マスでも。
- ナイト：L字形に、ある方向へ2マス進んでから横へ1マス。ほかの駒を飛び越えられる唯一の駒です。
- ポーン：前へ1マス。最初の位置からなら2マス進むこともできます。駒を取るときは斜め前へ1マス進みます。
駒はほかの駒を通り抜けられません（ナイトを除く）。相手の駒がいるマスに移動するとその駒を取ることができ、取られた駒は盤から取り除かれます。
# 特別な手
- キャスリング：キングがルークの方へ2マス動き、ルークはキングが通過したマスへ飛び移ります。キングとルークのどちらもまだ一度も動いておらず、間のマスがすべて空いていて、キングがチェックされておらず、攻撃されているマスを通過せず、移動先でチェックされない場合にだけ指せます。
- アンパッサン：ポーンが2マス進んで相手のポーンの真横に来たとき、その相手のポーンは、1マスだけ進んだものとみなしてそのポーンを取ることができます。ただし、すぐ次の手でだけです。
- プロモーション：いちばん奥の段に着いたポーンは、クイーン、ルーク、ビショップ、ナイトのうち好きな駒に変わります。
# チェックとゲームの終わり
攻撃されているキングは「チェック」の状態です。次の手で必ずチェックを解消しなければなりません。自分のキングがチェックされたままになる手は、決して指せません。
- チェックメイト：キングがチェックされていて、どの手でも防げない状態です。そのプレイヤーの負けです。
- ステイルメイト：手番のプレイヤーに指せる手がないのに、チェックはされていない状態です。引き分けになります。
- 次の場合も引き分けです：どちらもチェックメイトできなくなったとき（残りの駒が少なすぎる）、同じ局面が3回目に現れたとき、駒を取らずポーンも動かさずにお互い50手ずつ指したとき。
# チェス960
チェス960（フィッシャー・ランダム・チェス）は同じルールで遊びますが、最後列の駒は960通りの並べ方のうちの1つから始まり、並べ方は対局ごとにランダムに決まります。ポーンはいつもどおりに並び、黒の駒は白の駒と筋ごとに向かい合います。ビショップは必ず異なる色のマスに置かれ、キングは2つのルークの間のどこかに置かれます。
- キャスリング：キングとルークは、普通のチェスと同じマスで終わります。h側のルークとならキングはg、ルークはfに、a側のルークとならキングはc、ルークはdに来ます。キングとルークのどちらもまだ一度も動いておらず、2つが通るマスと止まるマスが（その2つを除いて）すべて空いていて、キングがチェックされておらず、攻撃されているマスを通過せず、移動先でチェックされない場合にだけ指せます。
- キャスリングするには、キングを、一緒にキャスリングするルークの上へ動かします。キングを移動先のマスへ動かしてもかまいません。ただし、キングが普通の手でもそこへ行ける場合や、すでにそこにいる場合は除きます。
# クレイジーハウス
手の種類が1つ増えたチェスです。取った駒は自分の色に変わって持ち駒になり、自分のバーに表示されます。駒を動かす代わりに、持ち駒を空いているマスに打つことができます。
- ポーンは1段目と8段目には打てません。打った駒でチェックをかけても、チェックメイトしてもかまいません。
- 昇格した駒が取られると、ポーンに戻って持ち駒になります。
- 駒不足による引き分けはありません。駒がゲームから消えることはないからです。
- 打つには、バーの駒をタップしてからマスをタップします（点が打てる場所を示します）。駒を盤までドラッグしてもかまいません。
# スリーチェック
チェスですが、先に3回チェックをかけたプレイヤーの勝ちです。チェックメイトでも勝ちです。各バーには3つの枠があり、そのプレイヤーがチェックをかけるたびに1つずつ赤く光ります。
# キング・オブ・ザ・ヒル
チェスですが、自分のキングを中央の4マス（d4、e4、d5、e5。金色の枠で囲まれています）のどれかに先に進めたプレイヤーが、その時点で勝ちです。チェックメイトでも勝ちです。キングを取られる位置へ動かせないのは同じです。
# アンチチェス
さかさまのチェスで、目的は自分の駒をすべて失うことです。
- 駒を取るのは義務です。取れるときは必ず取らなければなりませんが、どれを取るかは選べます。
- キングはふつうの駒です。チェックはなく、キングも取られることがあり、キャスリングもありません。ポーンはキングにも昇格できます（選択肢の5番目）。
- 自分の駒がなくなったとき、または動かせる手がなくなったときに勝ちです。
- ビショップしか残っておらず、両者のビショップが異なる色のマスにいるときは引き分けです。お互いに取り合うことができないからです。
# アトミックチェス
駒を取るたびに爆発が起こります。取られた駒、取った駒、そしてまわりの8マスにあるポーン以外のすべての駒が盤から消えます。
- 相手のキングを爆発させれば勝ちです。自分のキングがチェックされていてもかまいません。チェックメイトでも勝ちです。
- キングは駒を取れません。また、自分のキングを爆発させる手は指せません。
- 2つのキングが隣り合っているときは、どちらもチェックではありません。片方を取れば両方が爆発するからです。
- どちらにも勝つのに十分な駒が残っていないときは引き分けです。
# レーシングキングス
すべての駒が最初の2列に並んで始まり、ポーンはありません。チェックをかける手は指せません。
- 金色の枠で囲まれた最後の列に最初に着いたキングの勝ちです。
- 白のキングが先に着いたら、黒にはもう1手あります。黒のキングも最後の列に着けば引き分けです。
# ホード
白はキングのいない36個のポーンで、ふつうの黒の軍勢と戦います。
- 白は黒のキングをチェックメイトすれば勝ち、黒は白の駒をすべて取れば勝ちです。
- 最初の列にある白のポーンも2マス進めます（そのときはアンパッサンで取られません）。
- 白にはキングがないので、チェックされることはありません。
# 端末での遊び方
駒をタップすると、動ける場所が表示されます。続けてマスをタップするか、駒をドラッグします。点は移動先を、輪は取れる駒を示します。チェックされたキングは赤く光ります。キャスリングするには、キングをルークの方へ2マス動かすか、ルークの上へ動かします。
