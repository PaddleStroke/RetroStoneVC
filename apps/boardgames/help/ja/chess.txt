チェス
# 目的
相手のキングをチェックメイトしましょう。つまり、逃げ場がないようにキングを攻撃します。白が先手です。
# 駒の動き
- キング：どの方向にも1マス。クイーン：縦・横・斜めのまっすぐな線上を何マスでも。ルーク：縦か横に。ビショップ：斜めに。
- ナイト：L字形に、ある方向へ2マス進んでから横へ1マス。ほかの駒を飛び越えられる唯一の駒です。
- ポーン：前へ1マス。最初の位置からなら2マス進むこともできます。駒を取るときは斜め前へ1マス進みます。
- 相手の駒がいるマスに移動すると、その駒を取ることができます。
# 特別な手
- キャスリング：キングがルークの方へ2マス動き、ルークはキングが通過したマスへ飛び移ります。キングとルークのどちらもまだ一度も動いておらず、間のマスがすべて空いていて、キングがチェックされておらず、攻撃されているマスを通過せず、移動先でチェックされない場合にだけ指せます。
- アンパッサン：2マス進んで相手のポーンの真横に来たポーンは、1マスだけ進んだものとみなして、その相手のポーンに取られることがあります。ただし、すぐ次の手でだけです。
- プロモーション：いちばん奥の段に着いたポーンは、クイーン、ルーク、ビショップ、ナイトのどれかに変わります。
# チェックとゲームの終わり
自分のキングがチェック（攻撃された状態）のままになる手は、決して指せません。
- チェックメイト：キングがチェックされていて、どの手でも防げない状態です。そのプレイヤーの負けです。
- 引き分け：ステイルメイト（指せる手がないのに、チェックはされていない状態）、チェックメイトするには駒が少なすぎるとき、同じ局面が3回目に現れたとき、駒を取らずポーンも動かさずにお互い50手ずつ指したとき。
# チェス960
最後列の駒はランダムな並び順で始まります。ビショップは異なる色のマスに、キングは2つのルークの間に置かれます。キャスリングは普通のチェスと同じマスで終わり（キングはg、ルークはf、またはキングはc、ルークはd）、2つが通るマスと止まるマスは、その2つを除いてすべて空いていなければなりません。キャスリングするには、キングを自分のルークの上へ動かします。
# クレイジーハウス
取った駒は自分の色に変わって持ち駒になります。駒を動かす代わりに、持ち駒を空いているマスに打つことができます。打った駒でチェックをかけても、チェックメイトしてもかまいません。ポーンは1段目と8段目には打てません。昇格した駒が取られると、ポーンに戻ります。駒不足による引き分けはありません。
# スリーチェック
先に3回チェックをかけたプレイヤーの勝ちです。チェックメイトでも勝ちです。
# キング・オブ・ザ・ヒル
中央の4マスのどれかに先に着いたキングの勝ちです。チェックメイトでも勝ちです。
# アンチチェス
目的は自分の駒をすべて失うことです：自分の駒がなくなったとき、または動かせる手がなくなったときに勝ちです。
- 駒を取るのは義務ですが、どれを取るかは選べます。
- キングはふつうの駒です：チェックはなく、キングも取られることがあり、キャスリングもありません。ポーンはキングにも昇格できます。
- ビショップしか残っておらず、両者のビショップが異なる色のマスにいるときは引き分けです。
# アトミックチェス
駒を取るたびに爆発が起こります：取られた駒、取った駒、そしてまわりの8マスにあるポーン以外のすべての駒が盤から消えます。
- 相手のキングを爆発させれば勝ちです。自分のキングがチェックされていてもかまいません。チェックメイトでも勝ちです。
- キングは駒を取れません。また、自分のキングを爆発させる手は指せません。2つのキングが隣り合っているときは、どちらもチェックではありません。
- どちらにも勝つのに十分な駒が残っていないときは引き分けです。
# レーシングキングス
ポーンはなく、チェックをかける手は指せません。最後の列に最初に着いたキングの勝ちです。白のキングが先に着き、すぐ次の手で黒のキングも着いたら引き分けです。
# ホード
白はキングのいない36個のポーンを持つので、チェックされることはありません。白はチェックメイトで勝ち、黒は白の駒をすべて取れば勝ちです。最初の列にある白のポーンも2マス進めます（そのときはアンパッサンで取られません）。
