バックギャモン
# 目的
自分の15個のチェッカー（駒）をすべて盤をぐるりと回してインナーボードに集め、それから盤の外へ出します（ベアオフ）。15個すべてを先にベアオフしたプレイヤーの勝ちです。ふたりは逆向きに進み、アイボリーはある向きに、エボニーはその反対向きに回ります。始める前にゲームを選びます：バックギャモン（いつもの初期配置のカード）、プラコト（チェッカーがすべて右側の2つの角にあり、1個が押さえられている）、フェヴガ（チェッカーがすべて対角の角にあり、それぞれ1個が先に出ている）、ロング・ナルディ（対角の角から2個ずつ出ていて、ダイスは6のゾロ目）。以下のルールはバックギャモンのもので、ほかの3つはその後で説明します。
# 盤
盤には細長い三角形（ポイント）が24あり、盤を4つに分けた各区画に6つずつあります。中央のバーが両側をそれぞれアウターボードとインナーボードに分け、2つのインナーボードはトレイのある側で向かい合っています。各プレイヤーは、自分のインナーボードの端のポイントを1として、相手のインナーボードの端の24まで番号を数えます。最初は、各プレイヤーが24ポイントに2個、13ポイントに5個、8ポイントに3個、6ポイントに5個のチェッカーを置きます。
# ダイスを振って動かす
最初に、各プレイヤーがダイスを1つずつ振ります。大きい目を出したほうが先手となり、振った2つの目をそのまま使います。同じ目なら振り直します。その後は交互に、ダイスを2つ振って、それぞれの目の数だけ動かします。
- 1つの目で1個のチェッカーを動かし、次にもう1つの目でチェッカーを動かします。同じチェッカーでも、別のチェッカーでもかまいません。
- チェッカーが止まれるのは、空いているポイント、自分のチェッカーがあるポイント、相手のチェッカーが1個だけあるポイントです。
- ゾロ目のときは、その目で4回動かします。
- 使える限り、両方の目を使わなければなりません。片方しか使えないときは、できれば大きいほうの目を使わなければなりません。
- 動かせる手がまったくないときは、その番は何もできません。
# ヒットとエンター
ポイントに1個だけあるチェッカーをブロットといいます。相手のブロットに止まるとヒットになり、そのチェッカーはバーに置かれます。バーにチェッカーがあるプレイヤーは、まずそれを盤に戻さなければなりません。ダイスの目が示す、相手のインナーボードのポイントにエンターします（1はバーからいちばん遠いポイントです）。相手のチェッカーが2個以上あるポイントはふさがっています。バーにある自分のチェッカーがすべてエンターするまで、ほかのチェッカーは動かせません。
# ベアオフ
15個のチェッカーがすべて自分のインナーボードに入ったら、ベアオフできます。ダイスの目と同じ番号のポイントからチェッカーを1個出します。そのポイントが空なら、できる限りそれより大きい番号のポイントからチェッカーを動かさなければなりません。それより大きい番号のポイントにチェッカーが1個もなければ、その目で、自分のチェッカーがあるいちばん大きい番号のポイントから1個出します。ヒットされたチェッカーがあると、それがインナーボードまで戻ってくるまでベアオフは再開できません。
# 勝ち
- 15個すべてを先にベアオフしたプレイヤーが1点を得ます。
- ギャモン：負けたプレイヤーが1個もベアオフしていなければ、勝者は2点を得ます。
- バックギャモン：負けたプレイヤーが1個もベアオフしておらず、さらにバーか勝者のインナーボードにチェッカーが残っていれば、勝者は3点を得ます。
このゲームではダブリングキューブを使いません。
# プラコト
各プレイヤーは15個のチェッカーをすべて自分の24ポイントに置いて始め、バックギャモンと同じく互いに逆向きに進みます。ヒットはなく、バーもありません。
- 相手のチェッカーが1個だけのポイントに止まると、そのチェッカーを押さえ込みます。押さえられたチェッカーは、上のチェッカーが去るまで動けません。そのポイントは押さえた側のものになり、さらにチェッカーを重ねられます。
- 「母」とは、自分の24ポイントに最後に残ったチェッカーです。そこで母が押さえられると、そのプレイヤーはただちに2点負けです。ただし、押さえた側が自分の24ポイントにまだチェッカーを残しているときは、そこが空になった時点で決着します。両方の母が押さえられたら引き分けです。
- 最初の振り分けに勝ったプレイヤーは、最初の手のためにもう一度ダイスを振ります。勝者は1点、負けた側が1個もベアオフしていなければ2点を得ます。
# フェヴガ
各プレイヤーは15個のチェッカーをすべて自分の24ポイントに置き、対角の角から始めます。両者とも盤を同じ向きに回ります。相手のスタートは自分の12ポイントです。ヒットはなく、チェッカーが1個あればそのポイントを押さえていて、相手はそこに止まれません。
- 自分の1個目のチェッカーが相手のスタートを通り過ぎるまで、2個目のチェッカーは自分のスタートを離れられません。
- 自分のスタートの区画の6ポイントすべてを占めることも、相手の15個すべてが後ろにいる状態で6ポイントを連続して占めることもできません。
- 最初の振り分けに勝ったプレイヤーは、最初の手のためにもう一度ダイスを振ります。勝者は1点、負けた側が1個もベアオフしていなければ2点を得ます。
# ロング・ナルディ
フェヴガと同じ初期配置と向きです。15個すべてを「頭」（自分の24ポイント）に置き、対角の角から、両者とも同じ向きに進みます。ヒットはなく、チェッカーが1個あればそのポイントを押さえています。
- 頭を離れられるのは1回の手番に1個だけです。自分の最初の振りに限り、6-6、4-4、3-3のときは2個まで離れられます。
- 相手のチェッカーが少なくとも1個その先にいない限り、6ポイントを連続して占めることはできません。
- 最初の振り分けに勝ったプレイヤーは、最初の手のためにもう一度ダイスを振ります。勝者は1点（オイン）、負けた側が1個もベアオフしていなければ2点（マルス）を得ます。
# 端末での遊び方
金色に光るダイスをタップすると振れます。チェッカーをタップしてから点のどれかをタップするか、ドラッグします。輪はヒットすることになるブロットを示します。1回の移動でダイスを1つ使い、使ったダイスは暗くなります。ベアオフするには、チェッカーを右のトレイへ動かします。バーにあるチェッカーは、はじめから選ばれています。振った目が使えないときは、そのダイスが赤く光り、番が移ります。自分のプレイヤーバーには、ベアオフしたチェッカーの数と、最後には得た点数が表示されます。「元に戻す」は1手ずつ取り消し、前の番のダイスは振ったときの目のまま戻ります。プラコトでは、押さえ込めるチェッカーにもリングが表示され、押さえられたチェッカーは押さえている側のチェッカーの下に置かれます。
