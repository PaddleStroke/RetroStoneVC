論理ゲート
# 目的
回路基板の下にはスイッチ、その上に論理ゲート、いちばん上にランプが並んでいます。電線は信号を下から上へ運びます。信号は0（暗いまま）か1（金色に光る）です。スイッチを切り替えて、すべてのランプを点けましょう。ただし、赤い警報ランプは消したままにします。全6章、150レベルです。ランダムな回路では、先に大きさを選びます。小（スイッチ3〜4個）、中（5〜6個）、大（7〜8個）です。
# ゲート
ゲートはクルミ材の札にはめ込んだ真鍮の形です。入力は下から入り、出力は上から出ます。ゲートの頂上にある小さな丸は、答えを反転させます。以下はすべての場合の入力と出力です。01 → 1 は「1つ目の入力が0、2つ目が1のとき出力は1」という意味です。ゲートには、回路図と同じように英語の名前（NOT、AND、OR、XOR、NAND、NOR）が刻まれています。
- NOT（否定）：先に丸の付いた三角形。入力の反対です。0 → 1、1 → 0。
- AND（論理積）：下が平らで上が丸いドーム形。入力がすべて1のときだけ1。00 → 0、01 → 0、10 → 0、11 → 1。
- OR（論理和）：先のとがった盾の形で、底がくぼんでいます。どれか1つでも入力が1なら1。00 → 0、01 → 1、10 → 1、11 → 1。
- XOR（排他的論理和）：ORの形の下にもう1本の曲線。入力が異なるとき1。00 → 0、01 → 1、10 → 1、11 → 0。
- NAND：丸の付いたANDのドーム。00 → 1、01 → 1、10 → 1、11 → 0。
- NOR：丸の付いたORの盾。00 → 1、01 → 0、10 → 0、11 → 0。
後のレベルには入力が3つのゲートもあります。AND、OR、NAND、NORの働きは同じで、XORは1の入力が奇数個のとき1になります。
# 分岐スイッチ
電線が左右に分かれる札です。信号は真鍮の道が向いている側へ進み、反対側は0になります。タップすると信号の行き先が反対側に変わります。
# 切れる電線
クリーム色の小さなヒューズが付いた電線があります。ヒューズをタップすると電線が切れて火花が散り、ヒューズから先は外れたように0になります。切った電線は元に戻せません。戻すには元に戻すボタンを使うか、レベルを最初からやり直します。ヒューズの数より切れる回数が少ないレベルもあります。残りの回数はバーに表示されます。
# 固定スイッチ
真鍮の板がねじ留めされたスイッチは切り替えられません。
# レベルと星
各章の内容：1 NOT・AND・OR・XOR（スイッチ2〜3個）、2 NAND・NOR・警報ランプ・固定スイッチ（スイッチ5個まで）、3 分岐スイッチ（6個まで）、4 切れる電線（8個まで）、5 3入力のゲート、複数のゲートにつながるスイッチ、2つのランプ、6 スイッチ7〜8個ですべてが混ざった大きな回路。章のタブの後ろにあるサイコロのタブでは、上で説明した選び方で新しい回路をランダムに作ります。
1手はスイッチを1回切り替えるか、電線を1本切ることです。各レベルには、解くのに必要な最少手数（パー）があります。パーで解けば星3つ、2手多いまでなら星2つ、それ以外は星1つです。ヒントを使うと星は最大2つになります。元に戻すで1手戻すと、その手は数えられなくなります。解いたレベルと、まだ解いていない最初の3つのレベルを遊べます。
# 端末での遊び方
- レベル一覧：章ごとのタブと、その章のレベルが並びます。解いたレベルは星付きの金色、遊べるレベルは木の色、ロック中のレベルは暗い木の色です。レベルをタップすると始まります。獲得した星は端末に保存されます。
- スイッチをタップすると切り替わり、分岐スイッチをタップすると向きが変わり、ヒューズをタップすると電線が切れます。変化はゲートからゲートへと電線を上っていきます。
- 基板の横：章とレベルの番号、丸い矢印でレベルをやり直し、ランプでヒントが出ます（次に変える部品が点滅します）。代わりにやり直しボタンが点滅したら、電線の切り方がまちがっています。元に戻してください。
- すべてのランプが点くと金色に輝き、続いて獲得した星と次のレベルへのボタンが表示されます。新しいゲーム（格子のボタン）でレベル一覧に戻ります。
- バーには、スイッチの横に手数、ヒューズの横に残りの切断回数、星の横にパーが表示されます。横長の画面では、深い回路が横向きになることがあります（スイッチが左、ランプが右）。
