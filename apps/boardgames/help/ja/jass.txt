ヤス
# 目的
Schieber（「押しつけ」）です。2人ずつのチームが2つで、パートナーは向かい合って座ります。先に1000点（ロングゲームでは2500点）に達したチームの勝ちです。
# カード
6からエースまでの36枚です。
# ディール
各プレイヤーに9枚ずつ配り、ディールごとにディーラーが1席ずつずれます。ディーラーの次の人がゲームを選び、最初のトリックをリードします。
# ゲームを選ぶ
- 切り札のスートを指名するか、Obenabe（切り札なし、エースが最強）またはUndeufe（切り札なし、6が最強）を選びます。
- または押しつけます（schieben）。その場合はパートナーが必ず選びますが、最初のトリックは押しつけた人がリードします。
# 切り札
- 切り札：ジャック（Puur、20点）、次に9（Nell、14点）、エース11、キング4、クイーン3、10は10、8、7、6。
- ほかのスート：エース11、キング4、クイーン3、ジャック2、10は10、9、8、7、6。
- Obenabe：エースから6の順で、8は8点。Undeufe：6からエースの順で、6は11点、8は8点、エースは0点です。
- 最後のトリックにはさらに5点が加わります。Match（9トリックすべて）は257点です。
# 遊び方
- 最初に出されたスートのカードか、切り札を出します。そのスートのカードがなければ、どのカードでもかまいません。
- ほかのスートがリードされたとき、すでにトリックに出ている切り札より弱い切り札は出せません。ただし手札が切り札だけなら出せます。
- 切り札がリードされたら切り札で応じます。Puurを出す必要はありません。
- ObenabeとUndeufeでは、出せるなら同じスートのカードを出すだけです。
# Weis と Stöck
- Weis（役）は最初のカードを出すときに宣言します。同じスートの連続（6からエース）：3枚が20点、4枚が50、5枚が100、6枚が150、7枚が200、8枚が250、9枚が300。ジャック4枚が200、9の4枚が150、エース、キング、クイーン、10のいずれかの4枚が100です。
- いちばん良いWeisを1つ持つチームだけが得点し、そのチームのWeisがすべて数えられます。
- Stöck：切り札のキングとクイーンを1人で持っていると20点で、2枚目を出したときに数えます。
# 得点
- 各チームはカードの点数、Weis、Stöckを得ます。
- ロングゲームでは倍率をかけます。ダイヤとハートは1倍、スペードとクラブは2倍、ObenabeとUndeufeは3倍です。
# ゲームの終わり
Stöckは出したときすぐに数え、Weisは最初のトリックのあと、トリックの点はディールの終わりに数えます。ディールは必ず最後まで行います。同じディールのトリックで両チームが目標を超えたら、合計の高いほうの勝ちです。
