Portes logiques
# Le but
Chaque fil porte un signal des interrupteurs vers les lampes : 0 (sombre) ou 1 (doré, lumineux). Règle les interrupteurs pour que toutes les lampes s'allument, tandis que les lampes d'alarme rouges restent éteintes.
# Les portes
Chaque porte fait de ses entrées une seule sortie ; son nom y est gravé. Un petit rond sur une porte inverse sa réponse.
- NON (NOT) : le contraire de son entrée.
- ET (AND) : 1 seulement si toutes ses entrées valent 1.
- OU (OR) : 1 si au moins une entrée vaut 1.
- OU exclusif (XOR) : 1 si ses deux entrées diffèrent ; avec trois entrées, quand un nombre impair d'entre elles vaut 1.
- NON-ET (NAND) : le contraire du ET.
- NON-OU (NOR) : le contraire du OU.
# Les aiguillages
Là où le fil se divise, le signal continue du côté où pointe la piste de laiton ; l'autre côté porte 0. Touche-le pour envoyer le signal de l'autre côté.
# Les fils à couper
Touche un câble volant pour le couper : après la coupure, le fil porte 0. Seuls Annuler ou recommencer le niveau le réparent. Certains niveaux permettent moins de coupures qu'ils n'ont de câbles.
# Les interrupteurs verrouillés
Un interrupteur barré d'une plaque de laiton vissée reste comme il est.
# Niveaux et étoiles
Un coup, c'est une bascule ou une coupure. Résolu au par, le moins de coups qui le résolvent : 3 étoiles ; jusqu'à deux coups de plus : 2 étoiles ; sinon 1. Un indice limite le niveau à 2 étoiles.
