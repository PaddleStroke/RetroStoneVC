Cases libres
# Le but
Monter les 52 cartes sur les quatre fondations, une par couleur, de l'as au roi.
# La mise en place
- Les 52 cartes sont posées face visible en huit colonnes, sous quatre cases libres et les quatre fondations.
# Déplacer les cartes
- Déplace la carte du dessus d'une colonne : sur une carte d'un rang de plus, rouge sur noir ou noir sur rouge ; dans une case libre vide ; ou sur sa fondation.
- Chaque case libre reçoit une carte. N'importe quelle carte peut aller dans une colonne vide.
- Une suite se déplace d'un coup s'il y a la place de la déplacer carte par carte : autant de cartes que de cases libres vides plus une, doublé pour chaque colonne vide (sans compter la colonne d'arrivée).
- Une carte posée sur une fondation y reste.
# Les donnes
Les donnes sont numérotées de 1 à 32000, comme dans les autres versions du jeu ; toutes se gagnent, sauf la donne 11982.
# La fin de la partie
Tu gagnes quand toutes les cartes sont sur les fondations.
# Niveaux et étoiles
3 étoiles : sans indice ni coup annulé.
