Code secret
# Le but
L'appareil cache un code de fiches de couleur sous le couvercle, au bout du plateau. Trouve-le seul, avant d'avoir utilisé toutes les rangées. Choisis d'abord la partie :
- Facile : 4 fiches, 6 couleurs, 10 rangées. Aucune couleur n'apparaît deux fois dans le code.
- Classique : 4 fiches, 6 couleurs, 10 rangées. Les couleurs peuvent se répéter.
- Difficile : 5 fiches, 8 couleurs, 12 rangées. Les couleurs peuvent se répéter.
# Un coup
Remplis la rangée vide suivante, une fiche dans chaque trou, puis fais-la vérifier. Une proposition peut utiliser plusieurs fois la même couleur. De petites fiches répondent alors à côté de la rangée :
- une foncée pour chaque fiche de la bonne couleur dans le bon trou ;
- une claire pour chaque autre fiche dont la couleur est dans le code, mais dans un autre trou. Chaque fiche du code ne répond qu'une fois.
Les foncées viennent d'abord, puis les claires : elles ne disent jamais de quelles fiches elles parlent.
# La fin de la partie
Tu gagnes dès qu'une rangée reproduit le code : toutes ses fiches de réponse sont foncées. Si la dernière rangée est vérifiée et que le code reste caché, tu perds. Dans les deux cas, le couvercle glisse et dévoile le code.
# Jouer sur l'appareil
Touche une couleur dans la réserve : elle va dans le trou marqué, et la marque passe au trou vide suivant. Touche un trou pour le marquer, touche-le encore pour changer sa couleur, ou fais glisser une fiche de la réserve jusqu'à un trou. Quand la rangée est pleine, touche le bouton de vérification. Annuler reprend la dernière fiche posée ; une rangée vérifiée reste. Chaque couleur porte aussi son propre signe, pour distinguer les fiches sans les couleurs. La barre indique combien de rangées il reste.
