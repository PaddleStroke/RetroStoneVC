Code secret
# Le but
Trouve seul le code caché de fiches de couleur, avant d'avoir utilisé toutes les rangées. En partie facile, aucune couleur n'apparaît deux fois dans le code ; sinon, les couleurs peuvent se répéter.
# Un coup
Remplis la rangée suivante, une fiche dans chaque trou, puis fais-la vérifier. De petites fiches répondent :
- une foncée pour chaque fiche de la bonne couleur dans le bon trou ;
- une claire pour chaque autre fiche dont la couleur est dans le code, mais ailleurs. Chaque fiche du code ne répond qu'une fois.
Les fiches de réponse ne disent jamais de quelles fiches elles parlent.
# La fin de la partie
Tu gagnes dès qu'une rangée reproduit le code : toutes ses fiches de réponse sont foncées. Si la dernière rangée échoue, tu perds.
