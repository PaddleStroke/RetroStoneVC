Permainan Marienbad
# Tujuan
Korek api tersusun dalam beberapa baris. Dengan aturan "yang terakhir kalah" (aturan klasik), pemain yang mengambil korek api terakhir kalah. Dalam permainan biasa, pemain yang mengambilnya menang. Pihak terang jalan lebih dulu.
# Satu giliran
Ambil satu korek api atau lebih, sebanyak yang kamu mau, tetapi semuanya dari baris yang sama. Ketuk korek apinya, lalu tombol bundar bertanda centang.
