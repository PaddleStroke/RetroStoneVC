Secret Code
# The aim
Find the hidden code of coloured pegs on your own before the rows run out. In the gentle game no colour appears twice in the code; otherwise colours may repeat.
# A move
Fill the next row with a peg in each hole, then check it. Small pegs answer:
- A dark peg for each peg of the right colour in the right hole.
- A light peg for each other peg whose colour is in the code, but elsewhere. Each code peg answers only once.
The answer pegs never tell which of your pegs they mean.
# The end of the game
You win as soon as a row matches the code: all its answer pegs are dark. If the last row fails, you lose.
