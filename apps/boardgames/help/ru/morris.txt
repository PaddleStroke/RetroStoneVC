Мельница
# Цель игры
Оставьте соперника только с двумя фишками или без ходов. У каждого игрока девять фишек. Первыми ходят светлые. Перед партией выберите доску: мельница с девятью фишками (карточка с тремя квадратами), мельница с двенадцатью фишками (три квадрата, соединённые в углах диагоналями) или мельница с шестью фишками (два квадрата). Правила ниже — для мельницы с девятью фишками; две другие игры меняют их так, как описано дальше.
# Расстановка
Сначала игроки по очереди ставят по одной фишке на любой свободный пункт, пока все восемнадцать фишек не окажутся на доске.
# Ходы
Затем в свой ход передвиньте одну из своих фишек по линии на соседний пункт, если он свободен. Игрок, у которого осталось только три фишки, может «летать»: переставлять фишку на любой свободный пункт.
# Мельницы
Три ваши фишки в ряд на одной линии образуют мельницу. Каждый раз, когда вы строите мельницу, при расстановке или при ходах, снимите с доски одну фишку соперника. Нельзя снимать фишку, стоящую в мельнице, если только все его фишки не стоят в мельницах. Если открыть мельницу и снова её закрыть, получится новая мельница.
# Мельница с двенадцатью фишками
Доска мельницы с девятью фишками, и в каждом углу — диагональ, соединяющая три квадрата. У каждого игрока двенадцать фишек. Фишки ходят и по диагоналям, а три фишки на диагонали тоже составляют мельницу. Если при расстановке заполнятся все 24 пункта, это ничья.
# Мельница с шестью фишками
Доска поменьше: два квадрата, соединённые короткими линиями посередине сторон. У каждого игрока шесть фишек. Мельницу составляют три пункта на каждой стороне квадрата; короткие линии между квадратами служат только для ходов. «Летать» нельзя: игрок, у которого осталось две фишки, проигрывает.
# Конец партии
- Игрок, у которого осталось две фишки, проигрывает.
- Игрок, который не может сдвинуть ни одной фишки, проигрывает.
- Партия заканчивается вничью, когда одна и та же позиция повторяется в третий раз или после пятидесяти ходов каждой стороны без мельницы.
# Игра на устройстве
Нажмите на свободный пункт, чтобы поставить фишку. Чтобы сделать ход, нажмите на свою фишку, а затем на её новый пункт, или перетащите её. После мельницы фишки, которые можно снять, светятся: нажмите на одну из них.
