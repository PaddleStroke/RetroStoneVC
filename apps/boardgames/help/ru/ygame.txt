# Цель игры
Соедините все три стороны треугольника одной группой своих камней. Угловая клетка принадлежит обеим сторонам, которые в ней сходятся. Первыми ходят белые.
# Ход игры
- Игроки по очереди ставят по одному камню на любую свободную клетку. Камни никогда не двигаются, и их никогда не берут.
- Два ваших камня соединены, если их клетки соприкасаются стороной.
- Ничьей не бывает.
# Обмен
Только на втором ходу чёрные могут вместо того, чтобы ставить камень, забрать себе первый камень белых: камень становится чёрным на своём месте. Затем снова ходят белые.
