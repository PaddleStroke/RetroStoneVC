# Цель игры
Соедините все три стороны треугольника одной группой своих камней. Угловая клетка принадлежит обеим сторонам, которые в ней сходятся. Первыми ходят белые (светлые).
# Ход игры
- Игроки по очереди ставят по одному камню на любую свободную клетку. Камни никогда не двигаются, и их никогда не берут.
- Два ваших камня соединены, если их клетки соприкасаются стороной: у каждой клетки шесть соседей.
- Ничьей не бывает: когда доска заполнена, один из игроков всегда уже соединил все три стороны.
# Обмен
Право первого хода даёт большое преимущество. Только на втором ходу чёрные могут вместо того, чтобы ставить камень, забрать себе первый камень белых: камень становится чёрным на своём месте. Затем снова ходят белые.
# Конец партии
Побеждает тот, кто первым соединит все три стороны.
