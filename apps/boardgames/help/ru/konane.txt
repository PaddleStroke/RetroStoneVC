Конане
# Цель игры
Станьте последним игроком, который ещё может ходить. Каждый ход — прыжок, который берёт камень. Первыми ходят тёмные.
# Начало
Тёмный игрок снимает один из своих камней с одного из четырёх центральных полей или из угла. Затем светлый игрок снимает один из своих камней рядом с этой дыркой.
# Взятие
Перепрыгните своим камнем через камень соперника, лежащий вплотную к нему (вверх, вниз, влево или вправо), на пустое поле сразу за ним, и возьмите его. Тот же камень может прыгать дальше по той же прямой, но никогда не может повернуть. Остановиться можно после любого прыжка.
# Конец партии
Проигрывает первый игрок, который не может сделать ход, когда наступает его очередь. Ничьих не бывает.
