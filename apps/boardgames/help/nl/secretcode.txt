Geheime code
# Het doel
Vind in je eentje de verborgen code van gekleurde pinnen voordat de rijen op zijn. In het makkelijke spel komt geen kleur twee keer in de code voor; anders mogen kleuren terugkomen.
# Een zet
Vul de volgende rij met een pin in elk gat en laat hem dan controleren. Kleine pinnen antwoorden:
- Een donkere voor elke pin van de juiste kleur in het juiste gat.
- Een lichte voor elke andere pin waarvan de kleur in de code zit, maar ergens anders. Elke pin van de code antwoordt maar één keer.
De antwoordpinnen zeggen nooit welke van je pinnen ze bedoelen.
# Het einde van het spel
Je wint zodra een rij gelijk is aan de code: al zijn antwoordpinnen zijn donker. Mislukt de laatste rij, dan verlies je.
