MAIN SESUKAMU
• Kontrol sentuh sederhana, dibuat untuk tiap game
• Gamepad Bluetooth dan USB juga bisa, hingga 4 pemain di banyak game
• Keluar dari game kapan saja: game menunggumu tepat di tempat kamu berhenti
• Skor terbaikmu tersimpan di ponselmu

TANPA IKLAN, TANPA PELACAKAN
• Sekali beli untuk semua game: tanpa iklan, tanpa pembelian dalam aplikasi, tanpa akun
• Tidak ada data yang dikumpulkan; bisa dimainkan offline
• 22 bahasa
