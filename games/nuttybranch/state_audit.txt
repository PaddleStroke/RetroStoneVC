# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.

draw.lc_hang        tests only
draw.lc_unhung      tests only
draw.lc_worst       tests only
draw.marg_rec       widescreen: the sprites drawn in the margins this frame (scratch: cleared before each frame's sprites)
draw.marg_nrec      their count (scratch)
draw.wide_extra     widescreen: set while drawing what only a wider screen draws (scratch: 0 between frames)
draw.tl_row         a tall screen: the branch's registers on the lines past the stage (scratch: draw_frame fills them before the frame is drawn)

draw.tl_bg3x        (the same)

draw.tl_ui0         (the same)

draw.obj_extra      a tall screen: set while drawing what only a tall screen draws (scratch: 0 between frames)
