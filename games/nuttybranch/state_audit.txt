draw.last_sel       the raster callback's last bark palette: reset on line 0 of every frame
draw.lc_seen        tests only (--opt lodcheck=1): the sizes seen of each object (never in a run)
draw.lc_on          tests only: the lodcheck option
draw.lc_objects     tests only: counters of the lodcheck report
draw.lc_steps       tests only
draw.lc_back        tests only
draw.lc_jumps       tests only
draw.lc_far         tests only
draw.lc_anchors     tests only
draw.lc_off         tests only
draw.lc_kept        tests only
draw.lc_hang        tests only
draw.lc_unhung      tests only
draw.lc_worst       tests only
draw.marg_rec       widescreen: the sprites drawn in the margins this frame (scratch: cleared before each frame's sprites)
draw.marg_nrec      their count (scratch)
draw.wide_extra     widescreen: set while drawing what only a wider screen draws (scratch: 0 between frames)
