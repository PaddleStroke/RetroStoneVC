# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.
# Everything else is registered in the game's state functions (main.c game_state(), draw.c draw_state(),
# the house kit's hu_state() and ha_state()).
main.snd_buf        sound_init(): the synthesis buffer (the samples are made at start-up, not saved)
main.SV             the battery save's copy (best scores, medals): stays in the .srm, a state never takes it back
draw.canvas         foreground(): the ground's canvas, cleared and redrawn every frame (widescreen: as wide as the screen)
draw.CX0            foreground(): the canvas's stage x, set every frame from the width
draw.CW             foreground(): the canvas's width, set every frame from the width
draw.CY0            foreground(): the canvas's stage y, set every frame from the height (a tall screen)
draw.CH             foreground(): the canvas's height, set every frame from the height (a tall screen)
draw.tile_slot      tile_id(): the ground's tiles shared within one frame (widescreen), cleared every frame
draw.tile_seen      tile_id(): the pictures of those tiles, rewritten every frame
draw.ui_pin         a tall screen: the UI layer pinned on the screen (house_tall.h ht_pin: the title, the panels), set by draw_frame before every picture (the raster shows it there)
