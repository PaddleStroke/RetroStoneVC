# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.
# Everything else is registered in the game's state functions (main.c game_state(), draw.c draw_state(),
# the house kit's hu_state() and ha_state()).
main.snd_buf        sound_init(): the synthesis buffer (the samples are made at start-up, not saved)
main.SV             the battery save's copy (best scores, medals): stays in the .srm, a state never takes it back
draw.fbuf           field(): the marbles' layer drawn in pixels, scratch, made again every frame
draw.fb_w           field(): its width (the screen's), set every frame
draw.fb_ox          field(): its stage origin (rs_screen_origin_x()), set every frame
draw.hud_pinned     a tall screen: the HUD band pinned at the screen's top, set by draw_frame before every picture
draw.sky_lines      a tall screen: the sky's lines at its top, from the height (tall_init: a setting, not a state)
