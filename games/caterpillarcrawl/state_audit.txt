# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.
# Everything else is registered in the game's state functions (main.c game_state(), draw.c draw_state(),
# the house kit's hu_state() and ha_state()).
main.snd_buf        sound_init(): the synthesis buffer (the samples are made at start-up, not saved)
main.SV             the battery save's copy (best scores, medals): stays in the .srm, a state never takes it back
draw.lawn_sx        a tall screen: the garden's scroll for the lawn past the stage, set by draw_frame before every picture
draw.lawn_sy        ... the same
draw.hud_top        a tall screen: the HUD drawn at the screen top during a run, set by draw_frame before every picture
draw.uv             portrait: the upright bed, from the screen's height in draw_init (fixed for a run; a state loads in either view)
draw.plot_x         portrait: the plot's place on the stage, set by draw_init from the screen
draw.plot_y         ... the same
draw.pano_off       ... the same (the upright garden's line at the screen's top)
draw.ui_y           ... the same (the stage's origin: the UI centred on the bed)
draw.narrow_out     portrait title: its layout (house_tall.h: the A glyph, the slots), set by screen_text every frame before the sprites
draw.ui_pin         a tall screen: the UI layer pinned on the screen (house_tall.h ht_pin: the title, the panels), set by draw_frame before every picture (the raster shows it there)
