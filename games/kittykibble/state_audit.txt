# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.
# Everything else is registered in the game's state functions (main.c game_state(), draw.c draw_state(),
# the house kit's hu_state() and ha_state()).
main.snd_buf        sound_init(): the synthesis buffer (the samples are made at start-up, not saved)
main.SV             the battery save's copy (best scores, medals): stays in the .srm, a state never takes it back
play.bot_dk         the bot's scratch (breadth-first distances): filled anew at each decision
play.bot_tv         the bot's scratch (when a vacuum can reach each cell): filled anew at each decision
play.bot_first      the bot's scratch (the first step of each path): filled anew at each decision
play.bot_q          the bot's scratch (the breadth-first queue): filled anew at each decision
play.bot_up         the bot's scratch (each cell's parent): filled anew at each decision
play.bot_tmp        the bot's scratch (a vacuum's distances): filled anew at each decision
play.bot_safe       the bot's scratch (the safe cells): filled anew at each decision
play.bot_reach      the bot's scratch (how deep the safe corridors go): filled anew at each decision
play.bot_sim        the bot's look-ahead: a copy of the world played on, made anew at each decision
draw.ui_slide       a tall screen: the game-over panel's slide for the raster, set by draw_frame before every picture
draw.narrow_out     a zoomed title's layout (the A glyph, the slots): set by screen_text every frame before the sprites
draw.ui_pin         a tall screen: the UI layer pinned on the screen (house_tall.h ht_pin: the title, the panels), set by draw_frame before every picture (the raster shows it there)
