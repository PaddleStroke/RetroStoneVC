# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.
# Everything else is registered in the game's state functions (main.c game_state(), draw.c draw_state(),
# the house kit's hu_state() and ha_state()).
main.snd_buf        sound_init(): the synthesis buffer (the samples are made at start-up, not saved)
main.SV             the battery save's copy (best depth, medals): stays in the .srm, a state never takes it back
play.G              well_settle(), fall_tick(): the block groups, worked out again from the well every time (scratch)
play.SIMW           the bot's look-ahead: a copy of a well played forward, made again at each decision (scratch)
draw.drawn_width    the width the maps were set up for: a setting of the frontend (draw_state_loaded sets the maps up again)
draw.slot_tall      a tall screen's ring slots (which row each holds): a cache of the maps, cleared by draw_state_loaded
draw.hud_pinned     a tall screen: the 1-player HUD pinned at the screen's top, set by draw_frame before every picture
draw.ui_cols        the UI columns shown (house_narrow.h hn_cols), set by draw_frame before every use
