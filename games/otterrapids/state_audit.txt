# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.
# Everything else is registered in the game's state functions (main.c game_state(), draw.c draw_state(),
# the house kit's hu_state() and ha_state()).
main.snd_buf        sound_init(): the synthesis buffer (the samples are made at start-up, not saved)
main.SV             the battery save's copy (best scores, medals): stays in the .srm, a state never takes it back
play.row_cache      pure course geometry keyed by seed and section ID; any cache miss rebuilds identical terrain
draw.bg1_sy        a tall screen: BG1's vertical scroll, set by draw_frame before every picture (raster_out, line 0)
draw.bg1_sx        ... BG1's horizontal scroll (the pause text in the columns shown), the same
draw.hud_pin       ... BG1's HUD lines pinned at the screen's top, the same
draw.fg_px         draw_frame's scratch: the foreground drawn each frame, then made into BG2's tiles
draw.tall_tile     ... a tall screen's tiles loaded this frame (each different tile once), the same
draw.tall_hash     ... their ids by hash, the same
draw.ui_pin         a tall screen: the UI layer pinned on the screen (house_tall.h ht_pin: the title, the panels), set by draw_frame before every picture (the raster shows it there)
