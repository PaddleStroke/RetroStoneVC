# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.
# Everything else is registered in the game's state functions (main.c game_state(), draw.c draw_state(),
# the house kit's hu_state() and ha_state()).
main.snd_buf        sound_init(): the synthesis buffer (the samples are made at start-up, not saved)
main.SV             the battery save's copy (best scores, medals): stays in the .srm, a state never takes it back
draw.draw_p1_x      tests only (--opt view=1, draw_view_log): where P1's sprite was last drawn, written every frame
draw.cam_x          the single view's camera: the world's scroll less the third on the left, set every frame before use
draw.tall_sx        a tall screen: BG2's scroll, set by draw_frame before every picture (the raster's line 0)
draw.tall_sy        ... the same
draw.hud_pinned     a tall screen: whether the HUD is pinned at the screen's top, set by draw_frame before every picture
draw.tall_pin_at    ... BG1's band pinned above the stage (the HUD, the zoomed title's logo): its screen line, the same
draw.tall_pin_n     ... its lines (0: none), the same
draw.tall_cam       ... the camera for the clouds above the stage, the same
draw.tall_b3x       ... BG3's scroll for the raster's line 0, the same
draw.tall_b3y       ... the same
draw.tall_split     ... whether the split screen shows (the earth under its views), the same
draw.tall_earth     ... the earth's colours under the split screen's views, the same
split.views_all     per frame: the views and a tall screen's two bands, passed to rs_viewports (rebuilt every frame)
