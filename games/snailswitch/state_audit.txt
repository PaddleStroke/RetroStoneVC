# Save states (tools/state_audit.py): the mutable statics that are NOT saved, and why.
# Everything else is registered in the game's state functions (main.c game_state(), draw.c draw_state(),
# the house kit's hu_state() and ha_state()).
main.snd_buf        sound_init(): the synthesis buffer (the samples are made at start-up, not saved)
main.SV             the battery save's copy (best scores, medals): stays in the .srm, a state never takes it back
draw.fg_px          the foreground's pixels: scratch, redrawn in full by foreground() every frame
draw.redraw_pause   transient: set by draw_state_loaded() after a state of another width, consumed by the next draw
draw.tall_sx        a tall screen: BG3's scroll x for the lines past the stage, set by draw_frame before every picture
draw.tall_fx        a tall screen: BG2's scroll x for the pool's lines and line 0, set by draw_frame before every picture
draw.tall_fy        a tall screen: BG2's scroll y (the shake) for line 0, set by draw_frame before every picture
draw.hud_lines      a tall screen: the HUD's band of BG1 pinned at the top (3-4 players; the title's logo), set by draw_frame every picture
draw.hud_y          a tall screen: that band's first screen line, set by draw_frame every picture
draw.p1_drawn_x     tests only (--opt view=1, draw_view_log): where P1's sprite was last drawn, written every frame
